# 恢复后自动读取插件状态

入口为本机管理后台的“备份恢复”和“插件列表”，需要登录后台。成功恢复后，页面丢弃旧插件状态和未保存草稿；首次返回插件列表时自动读取原全局或指定群范围，无需再点击刷新。搜索、筛选、排序和群号保留。

读取期间显示加载状态并暂停开关操作；失败时显示错误和刷新重试提示，不把读取失败显示成程序未注册插件。读取成功后显示恢复后的实际开关及响应规则。真正没有注册插件的成功结果仍显示空列表。

恢复前未完成的页面读取或保存响应不能回填新状态，也不会继续旧批量保存的后续项目；已经发往服务端的请求不能由页面撤销。切换到其他页面不改变恢复范围。此功能不发送 QQ 消息，不改变群权限或响应门控。

更新程序后重启 ZeroBot，刷新浏览器页面生效。恢复预览、覆盖确认、写前备份和原密码保持规则沿用既有行为。开发与验证记录见开发进度 DEV-64、自测 TC-84；2026-10-12真实Chrome独立恢复与首次返回已自动验收，日常程序已更新。
