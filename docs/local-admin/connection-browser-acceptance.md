# 连接设置的真实浏览器隔离验收

维护入口为 `go run scripts/start-admin-connection-acceptance.go`（仓库根目录，Windows，CGO_ENABLED=0）。临时程序与本机监听需要执行权限；页面自动化使用已连接Chrome。输出本次URL和私有`login.txt`路径；用本次随机密码登录并进入“连接设置”，分别检查两条正向连接、主人、Token保留/替换/清除、非法输入、新增/删除、确认与草稿保护。只有本次生成的回环模拟地址用于演练。

`status`读取本次状态，`check`向两台模拟OneBot各发送一次翻转指令并校验回复；`restart`校验已保存连接仅指向本次两个端点且保留正确测试Token/主人后，只重启本次程序，核对两台均重新握手、原密码仍可用、旧会话失效。守卫不满足时拒绝重启并保留实例，先通过页面恢复测试连接。`stop`或期限到达停止自有实例。每次运行新建目录，不删除原测试证据。

保存不立即改变运行连接；多连接编辑必须保留其他项及未知字段，重启提示与启动快照应一致。页面改动通过真实控件提交；控制器只准备合成环境、校验已保存状态及模拟通信，不用接口代替页面操作。模拟两账号不等于两个真实QQ或NapCat配置联动验收。
