## 1. 目标与边界

已确认的产品方向是本地管理后台，只管理用户自己的机器人。第一版以本机 Windows 为首要验收环境，管理一个 ZeroBot-Plugin 进程；已有配置允许多条 OneBot 连接，页面不能在保存时误删其余连接。

使用者是机器人的本机所有者。浏览器负责展示和操作，后端执行配置校验与插件控制，ZeroBot 承担消息处理，外部 OneBot 实现承担 QQ 登录和平台接入。

第一版包括状态、连接配置、插件管理、AI 设置、日志和配置备份。插件页现提供全局/指定群响应规则只读说明，区分响应检查与插件开关；网页修改响应、私聊响应管理和封禁编辑不在本次范围。以下内容暂不纳入：公网/局域网访问、多租户、用户注册、计费、多进程调度、扫码登录管理、动态安装 Go 插件、自动升级、后台进程托管。机器人仍按现有方式启动；需要重启的设置由页面明确提示。

代码备份分支与运行配置备份用途不同：分支保存代码；后台备份保存配置。聊天历史、媒体资源及插件全部数据库的整机备份不在第一版内，恢复界面必须列明覆盖范围。
