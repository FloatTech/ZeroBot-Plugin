# AI 未保存字段摘要

登录本机后台，进入“AI 设置”，读取配置后修改表单。页面上方“未保存字段摘要”按全局模型/人物设定、聊天会话参数、GPT温度三个表单列出已改动字段名称和数量，输入或选择变化后立即更新，改回最近读取或保存成功的页面基线会从摘要中移除。

摘要只显示固定字段名称，不显示新旧值、密钥输入、接口地址、提示词或人物设定正文。每个密钥的动作、输入和清除确认合并计为一个字段；列为“聊天密钥”等不代表已保存或密钥有效。未知表单字段统一显示“其他表单字段”，不展示其名称或内容。

全局表单使用全局范围；聊天/GPT摘要明确采用该表单成功读取或保存时的群号或私聊QQ，未点击“查看会话参数”的范围输入不会改变摘要目标。参数与同号群/私聊仍按原规则隔离。仅比较页面基线与当前输入，不查询服务端，不表示已经生效、配置有效或与外部最新修改一致；数字等沿用原草稿检测的输入文字比较方式，输入形式改变也可能计为未保存。

没有草稿时摘要隐藏。单独保存或放弃某一表单只更新该表单摘要，其他编辑保留；请求处理中保留摘要并提示等待，不自动保存。读取或保存失败/冲突保留原摘要，成功重新读取才替换；切换后台页面保留草稿与摘要，退出、会话过期或成功恢复配置后清空，迟到结果不能回填新会话。

本功能只帮助保存前核对，不产生额外请求、备份或配置写入，不发送QQ消息或调用模型。仍须在对应表单点击保存；生效时机、校验、备份、版本冲突、密钥清除确认和原编辑保护保持。

验收：分别修改人物设定、温度、密钥动作等，核对固定字段名称/合并数量/已加载范围；改回原值或确认局部放弃后摘要正确更新，无需保存日常配置或发送真实QQ消息。实际页面体验待验收。
