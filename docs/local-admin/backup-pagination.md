# 备份列表分页

登录本机后台进入“备份恢复”。筛选区域和恢复预览下方显示备份分页与列表，清理区域位于列表后。默认每页20份，可选择10、20或50份，再使用“上一页”“下一页”浏览；提示显示当前页、总页数及匹配结果中的条目范围。

分页只调整本次已加载列表的显示，不发送请求，也不创建、恢复或删除备份。筛选在全部已加载记录上执行，再按所选排序排列后分页；默认保留服务器原顺序，详见 [备份列表排序](backup-sort.md)。后台一次仍最多加载最新200份，分页不下载更早记录；存在未加载记录时继续提示该限制。

改变关键词、范围、校验状态、每页份数或清除筛选时回到第一页。点击页面内“刷新列表”或创建后的刷新保留当前页，结果数量减少时自动回到有效的最后一页。切换后台页面保留页码及每页份数；退出或会话过期恢复20份/第一页并清空缓存。浏览器重载页面重新从第一页/20份开始。没有结果时两边翻页按钮禁用。

读取、预览、恢复和清理请求中禁用分页，旧请求不会覆盖新会话。翻页不更改已打开的恢复预览或清理确认目标；预览仍明确显示备份编号，恢复仍需原确认和后端重新校验。打开恢复预览后页面滚动到该预览，便于核对编号；减少动画模式下使用即时滚动。

权限和保存范围不变：后台登录后使用，不读取备份文件内容或凭据，分页偏好只在当前页面内存，不写浏览器存储，不改变机器人配置、QQ登录、AI设定或历史。

验收：足够多的备份下翻页，核对边界、显示范围与无重复/遗漏；切换份数或筛选回到首页；打开预览后翻页确认编号不变，点击“刷新列表”后确认当前页有效。无需创建大量真实备份或恢复/清理日常状态，满200份、缩页和旧会话通过隔离测试覆盖。
