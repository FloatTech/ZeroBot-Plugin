# DeepSeek 风格小人人物设定

## 当前人物

Agent 使用 DeepSeek 社区「鲸鱼娘／蓝色大肥鱼」风格的 Q 版小人：蓝发蓝瞳、圆润大头、小巧身体，穿蓝白宽松连帽衫，带鲸鱼鳍发饰和小鲸尾装饰。称呼沿用机器人配置中的昵称；「小鲸」「蓝色大肥鱼」是可自然接住的昵称。该设定是参考社区形象的虚拟角色，不宣称是官方吉祥物或真实人物。

性格聪明、亲切、好奇，带一点软萌和轻微傲娇；偶尔呆萌自嘲，喜欢美食、游戏和计算机。吃饭、摸鱼等梗只在合适的闲聊里出现，认真提问先解决问题，不把每句话都写成角色表演。

## 查看和修改

1. 启动机器人后，打开本机后台 `http://127.0.0.1:3010/`，用后台密码登录。
2. 进入「AI 设置」，查看全局表单中的「Agent 人物设定」与「Agent 性别」。本次替换的是这两个字段，性别为「女」。
3. 按需编辑后，点击全局表单的「备份并保存」。保存会创建控制数据库备份，后续 Agent 请求使用新设定；已有对话记录保留。
4. 在已经开启 Agent 的会话中，与机器人聊天或询问「介绍一下你的形象」。群聊沿用原有 @、插件开关和响应条件；主人私聊可使用 Agent，普通成员私聊仍受原动作权限限制。

主人也可在私聊发送 `查看AI聊天Agent性格` 查看已保存设定。人物设定是实例共享的，全局修改会影响该机器人接下来的各群和私聊 Agent 请求，不会自动启用某个会话的 Agent。

本次更新的是文字人物设定，不会自动设置 QQ 头像、生成立绘或改变后台图标。普通聊天、`/gpt` 和群总结使用独立的「系统提示词」，本次保留其原值，因此不保证这些入口使用同一人物风格。

## 源码默认值与恢复

源码默认设定在 `third_party/zbputils/chat/char.yaml`。它在构建时嵌入程序，已保存的「Agent 人物设定」优先于源码默认值。只编辑 YAML 不会覆盖现有数据库；本次同时更新了数据库中的人物设定和性别，服务停止时写入的设置在下次启动后使用。

主人私聊命令 `重置AI聊天Agent性格性别` 会恢复**当前运行程序构建时**的默认设定。旧程序仍包含旧默认值；在使用包含新 YAML 的构建前，请通过后台编辑或恢复备份来调整，避免用该命令恢复出旧形象。

需要恢复之前的人物设定时，可在「备份恢复」预览本次控制数据库快照。恢复整个控制数据库也会恢复该快照中的其他控制设置，先核对预览；仅恢复人物时，可从保留的旧设定修改上述两个字段。不要清空对话档案来切换人物。

## 本次应用与验证

人物来源参考：[DeepSeek-chan 社区形象与表情包说明](https://github.com/the-beating-light-of-the-nail/deepseek-chan-meme-pack)。蓝白服装、鲸鳍发饰和 Q 版比例为本项目的具体设计选择。

验证记录为本机 `.local/whale-persona-verification.json`。本次没有替换运行程序或启动服务；新默认 YAML 将在以后构建时嵌入，已保存的人物设定在现有程序下次启动时即可使用。本次不发送真实 QQ 消息、不调用模型；真实聊天语气由用户后续体验验收。
