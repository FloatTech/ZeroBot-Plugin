# 连接设置未保存字段摘要

使用后台密码登录本机管理页，进入“连接设置”。修改已加载连接的地址、Token 操作或主人账号，或者填写“新增 OneBot 连接”，顶部“未保存字段摘要”随输入自动更新，分别显示各部分的固定字段名称与数量。改回页面基线后该字段移除，没有草稿时摘要隐藏；不要求保存日常配置即可核对。

当前连接最多显示“WebSocket 地址”和“Token”两项；Token 的操作、输入与清除确认合并计为一项。主人账号单列为启动配置范围。新增表单从默认正向、空地址、空 Token 和未勾选无 Token 的状态开始比较，分别显示“连接方向”“WebSocket 地址”和“Token”；Token 输入与无 Token 确认合并计数，改变方向也算草稿。

摘要不显示地址、Token、主人 QQ、新旧值、版本或配置正文。已有连接的标题只使用实际加载连接的方向与原序号，未提交的选择控件不能更改摘要目标；无法核对元数据时只显示通用目标提示，不展示原值。新增表单固定标为“尚未保存的新连接”，其默认方向不代表新增请求已提交。

摘要只比较当前页面输入与最近成功读取/保存后的页面基线，沿用原草稿文字比较；输入格式变化也可能计为未保存，不表示校验通过、服务端最新状态、已保存或正在运行。连接与主人属于启动配置，保存前按原规则备份，重启 ZeroBot 后生效；新增与现有连接/主人分别保存，不自动修改 NapCat、连接或重启。

单独放弃当前连接、主人或新增草稿只清对应摘要；切换连接按原确认规则处理当前连接草稿，主人与新增草稿保留。保存现有配置只更新现有连接/主人基线，新增草稿保留；成功新增或重新读取才按原行为替换草稿。忙时保留摘要并提示等待，失败或冲突保留，切换后台页面保留；退出、会话过期或成功恢复配置后清空，旧请求不能回填新会话。未读取、未登录或启动配置不可管理时隐藏摘要。

本功能只用于本地核对，不增加接口、配置写入、备份或浏览器存储。删除预览和已保存配置与本次启动的差异仍在原区域展示。

验收：修改地址、Token 操作、主人或新增方向，核对名称、数量和实际加载目标；改回原值或分别放弃后对应摘要消失。无需保存、重启或修改日常接入地址。
