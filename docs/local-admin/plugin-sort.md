# 插件列表排序

登录本机后台，进入“插件列表”，在搜索栏的“排序”下拉框选择：

- 默认顺序：最近读取的插件列表顺序。
- 名称：按中文语言环境比较名称，数字按数值排列，例如 plugin-2 在 plugin-10 前；比较相同的名称保留默认顺序。
- 启用优先、禁用优先：按最近读取或成功保存后的实际生效状态分组，状态未知始终在最后；同组保持默认顺序。
- 未保存优先：有开关草稿的插件先显示，同组保持默认顺序。草稿不算已生效状态。

排序作用于全部已加载的匹配插件，再按每页个数分页；不会只重排当前页。更换排序回到第一页，搜索、状态筛选和“只看未保存”可组合使用。“清除筛选”保留排序；选择“默认顺序”可恢复列表原顺序。

排序仅改变显示，不发送请求、不保存或放弃开关、不创建备份。所有页与隐藏项的草稿保留，用法窗口仍显示打开时的插件。修改、取消或保存草稿后重新排列，卡片可能移动到其他位置或页；顶部草稿数量仍包含隐藏项。单项保存仍对应所点击插件；“逐项保存全部草稿”仍按默认列表顺序提交全部草稿，显示排序不改变提交顺序。

排序在切换后台页面、刷新插件状态或成功切换全局/群范围时保留；切换范围后采用新范围的实际状态。请求失败保留最近成功列表和草稿。读取、单项保存及逐项保存期间禁用排序。退出、会话过期或浏览器重载后恢复默认顺序，不写浏览器存储；旧响应不能覆盖新登录的排序和列表。

验收：在多个分页间切换排序，核对已启用/禁用/未知顺序；编辑两项但不保存，选择“未保存优先”并组合搜索，核对草稿未丢失；清除筛选应保留排序，默认顺序应恢复原列表。无需为验收保存日常开关。实际页面体验待验收。

自动化验证：新增5项离线Chrome场景与原137项界面共142项全部通过；64项深浅主题/窄屏布局及截图、相关Go模块测试、静态检查和Windows构建通过。使用合成插件及模拟API，验证自然排序、稳定分组、草稿/分页/范围/用法、单项保存目标、逐项保存原顺序、忙时与新旧会话隔离。实际页面体验另待用户验收。

插件列表可下载当前已加载全局/群范围的全部匹配状态清单，沿用筛选与排序，草稿只标记未保存；仅导出最近已知插件开关状态，不能导入或恢复，见 [下载插件状态清单](plugin-state-catalog.md)。
