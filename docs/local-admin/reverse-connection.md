# 新增本机反向 OneBot 监听

登录本机后台进入“连接设置”，在“新增 OneBot 连接”表单选择“本机反向监听”，填写 ws://127.0.0.1:端口（例如 ws://127.0.0.1:6702）和新的 Token。确认后备份并保存，自动选择新增项。保存只修改启动JSON，不立即监听或重启；重启ZeroBot后加载。随后在自己的接入程序中配置WebSocket客户端，使用相同地址与Token连接ZeroBot。此操作不自动修改NapCat或登录账号，当前正向连接保持。

正向连接是ZeroBot主动连接接入程序的WebSocket服务器；反向监听是接入程序主动连接ZeroBot。连接列表中的“反向监听”不是TLS/wss加密连接，本项目锁定驱动使用普通HTTP WebSocket服务。新增入口因此仅接受ws、字面主机127.0.0.1、明确的1～65535十进制端口、空路径或根路径；不接受wss、外部主机、通配地址、查询参数、片段、地址中认证或自定义路径。原有非本机配置仍按原编辑入口读取和保存，不自动迁移。

反向新增必须填写有效Token，不提供无Token选项；最长2048字节，不能包含控制字符或使用脱敏占位。检查同一启动配置中已保存反向监听端口以及本机正向连接目标端口冲突，后台API也拒绝与当前后台监听端口相同；最多64条反向项。保存时不探测其他程序是否占用端口，不保证启动时空闲；遇到占用应在启动日志核对后更换端口或处理实际占用。

新增表单的类型、地址、Token和无Token选择一起作为草稿。切换方向保留地址/新Token，但切到反向会取消无Token选择并要求Token；只有正向可以明确无Token。选择方向本身记为草稿，重载或退出先确认，切后台页面保留。新增与已有连接/主人分别保存，已有草稿须先处理；放弃新增清空输入并回到正向。确认前后类型与内容变化不能提交旧确认，失败/冲突保留草稿，过期及旧响应不能回填新会话。预览删除与其他连接操作复用忙时保护，成功保存后Token输入清空。

写前备份、配置版本检查、原子替换、字段精度/其他连接/主人保留及待重启提示沿用原新增规则。接口旧客户端不传kind时仍新增正向；指定反向只写反向列表。新连接需改变本次运行配置时显示待重启；若恢复到启动时相同配置，则无需重复重启。

验收可只选择方向、填写模拟地址与Token后跨页返回/放弃，核对提示，不需改变日常NapCat配置。实际反向接入需按上述步骤设置自己的接入程序；隔离测试验证驱动监听、Token认证及模拟命令，不发送真实QQ消息。完整真实QQ业务仍保留原待办。
