# 本地管理后台 v0.1

日期：2026-10-13。这是本地管理后台的第一版范围，沿用ZeroBot-Plugin现有项目版本体系，不覆盖上游标签。

## 功能

- 本机回环访问、首次设置、密码登录与修改、退出和请求来源校验。
- 运行概览、多条OneBot连接增删改、主人账号与保存后待重启状态。
- 全局/群级插件开关、继承和实际生效原因，检索/排序/分页、草稿保护及用法下载。
- 共享AI配置、群/私聊参数、密钥保护、GPT引用处理、Agent持久上下文与角色动作边界。
- 脱敏日志、级别/关键词/起止时间筛选、暂停/清空/导出、深浅主题与小屏布局。
- 写前备份、手动备份、三类恢复预览/取消/确认、备份整理及恢复后重启检查。
- QQ文字/识图/群AI语音与原消息行为修复，模型/回复快照和资源观察工具。

使用步骤见[使用指南](user-guide.md)，安装与服务管理见[Windows环境](onebot-windows.md)及[运行维护](operations.md)。后台默认不对局域网或公网开放。

## 验证

现有界面/布局、实际Chrome页面流程、Windows隔离恢复/重启、模型与资源工具、真实QQ文字/图片/语音及角色会话命令验证保留各自范围。主人真实Agent查询本群、保存记忆、四条群回执和单次重启后的话题延续已通过。

最终交付核对已通过：242项界面、210项观察工具、64项离线布局、14个相关Go包（13包含测试）及vet、五个本地补丁模块的相关检查、Windows隔离整机与三类恢复/实际重启、14项观察参数守卫及路径身份夹具。五个补丁模块原始许可证完整保留，上游无断言的故意失败演示TestMaru明确跳过，不计为功能测试通过。

依据显式公开文件清单生成的独立源码副本可完成Windows构建，SHA-256与当前已验收运行程序一致；仅测试使用data子模块资源及经典诗歌缓存，未复制日常控制库、模型配置或凭据。公开文档链接、私有身份/运行资料排除及当前密钥内容检查通过。沙箱文件权限、测试夹具缺少词典及依赖模块单独开发配置问题已记录并处理，未改写初次失败为通过。原始私有资料保留本机；复验入口见[自测](self-test.md)。

## 限制与取消范围

剩余非主人Agent真人动作、QQ客户端体验及真实持续业务负载验收按使用者决定取消，不作为本轮交付条件，也不写成实测通过。已有模拟负载和20分钟资源窗口不证明长期无泄漏、并发峰值或所有模型/插件均正常；后续出现问题再优化。

QQ内置AI语音当前走群接口，私聊不得向其他群生成语音；Agent的非主人动作限于白名单和当前群。后台配置备份不包含聊天档案、QQ登录、媒体及全部插件数据库。其他操作系统没有本轮完整系统验收。

## 升级与交付

先备份本机配置、后台目录及需要保留的聊天档案，再从源码构建。仅更换ZeroBot时停止该服务并重启，保留NapCat登录；重新登录后台并核对连接、账号与已保存设置。程序更新不自动更改现有模型、角色或密钥。

GitHub交付使用中文提交与PR说明，目标为使用者自己的仓库。中间交流与本机调查统一保存在docs/local-notes并整体忽略；源码只包含实现与使用/开发资料，运行数据库、配置、日志、截图和原始聊天内容不上传。规则见[GitHub交付](github-delivery.md)。
