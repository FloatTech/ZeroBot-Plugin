# 异常日志筛选与排障入口

登录本机后台，在“运行概览”的近期异常区域点击“查看异常日志”，进入运行日志并应用“警告与错误”筛选，清空此前关键词。此组合包含 Warning、Error、Fatal 和 Panic，不包含 Info/Debug/Trace；只表示日志级别，不判断问题是否已解决。

运行日志的级别列表也可选择“警告与错误”并点击“应用筛选”。“只看异常”立即切换到该组合，保留当前已应用的关键词；“清除筛选”立即恢复所有级别且清空关键词。搜索内容按脱敏后的日志匹配。

页面标明当前已应用条件。输入框或级别下拉尚未提交的修改会提示“尚未应用”，查看和导出继续使用已应用条件；快速入口会把输入控件同步到实际条件。筛选切换从保留范围重新读取，旧筛选的迟到结果不会覆盖新列表。

快速筛选不改变暂停状态或自动滚动偏好；暂停时改变条件先清空列表，恢复更新后读取对应条件，导出仍可使用新的已应用条件。切页/隐藏/退出取消请求，退出或过期清空条件。草稿和条件不写浏览器存储。

权限和范围保持原规则：只供已登录本机后台使用；本次启动最多保留 1000 条日志，仍按容量/单条长度限制截断并脱敏。导出最多 1000 条仍保留记录，警告不等于业务错误；历史消息正文及凭据不展示，不读取任意日志文件或重启前日志。不修改机器人配置、不调用模型、不发送 QQ 消息。

验收：从概览打开异常日志，核对组合级别及提示；填关键词但不提交，核对“尚未应用”及导出仍按原条件；应用、只看异常、清除筛选后核对条件；暂停后改变筛选再恢复更新。无需故意制造真实故障，四类级别和迟到请求由隔离测试覆盖。

自动验证：两个后端用例覆盖四类异常/精确级别、增量分页/游标、读时脱敏、关键词、认证及查看/导出记录一致性；两个新增 DOM 和一个 Chrome 概览导航用例以及原44项，共47项界面测试通过。56项深浅主题/320～1280px布局通过，已核对桌面和窄屏日志截图，256字符连续关键词不造成横向溢出。Go模块/静态检查通过。

日常配置、AI密钥与人物设定保留；未发送真实QQ消息或调用真实模型。日志中已有素材MD5服务器网络警告仍可能出现，缓存素材可用；组合筛选只是帮助查阅记录，不把历史警告当作新增故障或已解决判定。实际体验见 TODO-LOG-ISSUES-01。

运行日志每条记录可点击“复制本条”，只复制页面已显示的时间、级别与脱敏正文，剪贴板受限时选中正文手动复制，详见 [复制本条日志](log-copy-entry.md)。
