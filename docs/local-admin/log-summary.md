# 日志匹配统计

登录本机后台，进入“运行日志”。在筛选条件下方查看“日志匹配统计”：显示读取完成的本地时间，以及最近一次成功读取时服务仍保留的日志里符合已应用条件的总数及Panic、Fatal、错误、警告、信息、调试、跟踪、其他级别数量。它使用和本次返回记录相同的保留快照，包含脱敏后关键词、级别和含边界的起止时间筛选。

匹配统计不受本次最多200条返回、增量游标或浏览器已显示条数影响。页面可能只加载最近200条；旧显示记录也可能已在服务端淘汰。统计只针对本次启动仍保留的最多1000条/约1MiB日志，不读取历史日志文件，不代表所有历史故障或问题已解决。重启、容量淘汰、更新筛选或新增记录都会改变统计；需要完整当前保留记录时用原“导出筛选日志”。

修改但未应用的筛选输入不影响当前统计。应用筛选或重新加载时清除旧统计，成功读取后再显示；暂停状态下更新筛选需恢复更新后读取。暂停、切页或页面隐藏停止刷新，保留上次成功统计；读取中断也保留旧统计并标明未刷新。恢复/重新进入后按原轮询更新。退出或会话过期清空，旧请求不能回填。旧版接口不提供或返回不一致计数时提示不可读取，不按页面条数猜测总匹配量。

统计只返回固定类别与数量，不输出原始消息、关键词、地址或密钥；关键词匹配继续在脱敏后执行，不能用统计搜索原始密钥。本页只读，不改变日志内容、机器人配置或备份，不额外调用模型，也不清理服务日志。

验收：刷新日志页查看匹配/保留及级别数量，再应用“仅看警告与错误”并核对统计范围。编辑关键词但未应用，统计应保持；暂停后不应自动改变，恢复后更新。数量是读取时的快照，有新日志时变化属正常；无需为验收在日常机器人制造异常。

暂停日志更新时可点击“读取一次”，按已应用条件读取新日志和匹配统计，完成后仍保持暂停，见 [暂停时读取一次日志](log-read-once.md)。

运行日志每条记录可点击“复制本条”，只复制页面已显示的时间、级别与脱敏正文，剪贴板受限时选中正文手动复制，详见 [复制本条日志](log-copy-entry.md)。

日志页可[清空当前显示](log-clear-display.md)：仅移除本页已显示记录，保留读取位置、筛选和更新状态，统计与导出仍使用服务保留记录；需要再次查看近期日志时重新加载后读取。
