# AI 设置真实浏览器自动验收

## 使用范围

日常使用入口为已登录后台的“AI 设置”。全局模型、聊天会话参数、GPT 温度分别保存；保存后后续请求生效，无需重启。密钥有保留、替换和明确确认清除三种操作，当前值不显示。切换后台页面保留未保存草稿；版本冲突保留编辑，重新加载核对后再保存。完整字段与权限见 [AI 设置](ai-settings-2026-10-02.md)、[草稿保护](ai-drafts.md) 和 [私聊参数](ai-conversations.md)。

自动验收使用 [隔离后台](isolated-admin-acceptance.md) 创建的独立程序、随机密码、控制库和模拟 OneBot。程序副本取自当前已部署版本，测试密钥和账号均为合成值；不读取日常密钥，不向 QQ 或真实模型发送请求。实例仅在本机随机端口开放，由已授权的 Chrome 操作。日常 3010 后台不用于保存或清除演练。

## 复验步骤

1. 从仓库执行 `go run scripts/start-admin-acceptance.go -binary-name zerobot.exe -lifetime 30m`，取得本次 `session.json` 的 URL 和 `login.txt` 的随机测试密码，登录独立后台。
2. 进入 AI 设置，核对初始模型 `isolated-edited-model` 与三个未配置密钥。将聊天、Agent、识图地址设为合成回环地址，例如 `http://127.0.0.1:1/chat`；填写合成模型和三种测试密钥后保存，核对三种密钥显示已配置、输入框恢复隐藏，基础检查不声称已调用模型。
3. 修改模型名后切换插件页再返回，核对草稿和字段摘要保留。改回已保存值，读取群 `101`；将聊天温度/概率和 GPT 温度设为不同值，先保存聊天，核对 GPT 草稿仍保留，再单独保存 GPT。
4. 切换到同号私聊 `101`，核对它不继承群的已保存参数，分别保存不同温度，再返回群确认未覆盖。这里的 `101` 只用于独立配置目标，不向该 QQ 或群发送消息。
5. 在第二个 Chrome 标签页读取相同配置并修改草稿，先在第一页保存新模型，再在旧页保存，核对冲突提示、草稿保留及按钮恢复可用。聊天群参数用同样方式核对。修正或恢复未保存字段后再关闭旧页。
6. 选择清除聊天密钥但不确认，点击保存应提示先确认且不新增备份；确认后保存，只清除聊天密钥。再确认清除识图和 Agent 密钥，核对字段和其他会话参数保持。无改动保存不新增备份；带查询参数的无效接口地址被拒绝，错误不回显合成认证文字。
7. 保存后等待草稿消失、控件恢复可用，再读取完整页面核对；连续保存会保留同样的成功提示，不能只凭该旧提示判断请求完成。重新加载完成后再切换群/私聊范围。
8. 在启动器输入 `restart`，仅重启本次实例。从更新后的 `session.json` 取得新 URL，确认旧会话失效，使用原测试密码重新登录；核对模型、三种密钥清除结果、群与私聊参数分别持久保存。输入 `stop` 停止实例。

独立后台与日常后台在同一主机名使用同一会话 Cookie，回到日常后台可能需要正常重新登录；日常密码文件保持。测试失败、早读状态或截图超时应单独记录，不能作为已通过。
