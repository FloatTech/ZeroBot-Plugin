# AI 按表单放弃更改

登录本机后台进入“AI 设置”，读取配置后，每个表单的保存按钮下方提供“放弃此表单更改”：全局模型与人物设定、聊天会话参数、GPT温度分别操作。只有该表单存在未保存更改时可点击。先确认表单名称或已读取的群/私聊标题，取消则保持全部编辑；确认后只恢复该表单最近读取或保存成功时的页面值，其他表单的草稿、选择及保存目标保持。

放弃全局表单会清空未保存的新密钥输入，恢复“保留当前密钥”、隐藏清除确认，并恢复该表单的模型、地址与人物设定等字段；不会读取或显示已有密钥。放弃聊天参数或GPT温度只恢复对应表单，不修改全局模型或其他会话表单。范围输入尚未读取时，仍以已加载表单的标题为准。

操作只恢复页面草稿，不发送请求、不创建备份、不撤销已保存的配置，不影响对话记录或正在执行的机器人任务。出现版本冲突后，放弃只恢复上次成功读取的页面值；需要重新加载设置以查看最新保存值。原保存、写前备份、后续请求生效、密钥替换/清除确认及版本保护保持。

读取或保存期间禁止放弃，退出或会话过期清空草稿；旧确认和旧请求不能恢复新会话的输入。没有读取配置或没有更改时按钮禁用，AI插件未编译时不能操作。草稿与基线只在页面内存，不写浏览器存储或文件。

验收：分别修改人物设定、聊天参数和GPT温度，不保存；放弃其中一项先取消再确认，核对其他两项仍有草稿。选择替换密钥时可用不含真实凭据的测试文字，放弃全局后确认新值清空、动作回到保留；无需保存或调用模型，忙时/冲突/过期场景用隔离测试覆盖。
