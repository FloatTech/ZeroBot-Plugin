# 插件列表分页

登录本机后台进入“插件列表”。搜索和生效状态筛选下方提供“上一页”“下一页”与“每页个数”，默认20个，可选10、20或50个；提示显示当前页、总页数与匹配记录范围。搜索名称/功能/用法、状态筛选先覆盖全部已加载插件，再按所选排序排列后分页；默认保持原注册列表顺序，其他方式见 [插件列表排序](plugin-sort.md)。

改变搜索、状态筛选或每页个数、清除筛选时回到第一页。切换全局/群范围成功后回第一页，读取失败保留旧范围、页码与草稿。点击“刷新插件状态”保留当前页；刷新或保存导致匹配结果减少、当前页超出范围时，页码校正到有效的最后一页。切换后台页面保留页码和每页个数；浏览器重载、退出或会话过期恢复第一页/20个。

翻页、筛选与切换每页个数只改变显示，不发送请求，不保存开关，也不丢弃草稿。顶部未保存数量涵盖全部页和隐藏的插件；返回原页仍可看到选择和“未保存”标记。每个插件仍单独点击“保存开关”，成功只清对应草稿，失败保留。保存后按实际生效状态重新筛选，草稿本身不会改变实际状态计数。

读取范围、刷新或保存期间禁用分页；退出或过期清空草稿和已加载插件，旧请求不能回填或解锁新会话。刷新插件状态、切群、退出仍按原规则确认丢弃草稿。用法弹窗内容始终对应打开时的插件，关闭弹窗后可继续翻页。

仅显示本程序真实注册、已编译的插件，权限与全局/群继承规则不变，不进行安装或批量启停。页码与每页个数只保存在当前页面内存，不写浏览器存储，不改变QQ、OneBot、AI设定或对话记录。

验收：在108个插件中翻页并切换份数；先编辑一个开关，不保存，翻到其他页再返回，核对草稿仍在；输入搜索/状态条件确认回首页；打开用法核对标题与内容，关闭后继续翻页。不需要为验收修改日常开关，保存、失败和过期场景使用隔离测试覆盖。
