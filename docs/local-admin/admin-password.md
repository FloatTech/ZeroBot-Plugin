# 修改后台密码

登录本机后台进入“后台安全”。填写当前后台密码、新密码及新密码确认，点击“修改密码并退出”后确认。新密码至少12个字符、不超过512字节，需与旧密码不同；不自动去掉首尾空格。这里仅管理后台密码，与QQ登录、OneBot Token和模型密钥分别设置。

成功保存后所有后台会话失效，当前页面返回登录页，用新密码重新登录；其他标签页或浏览器在下次请求时要求重新登录。机器人和NapCat无需重启，消息处理保持运行。已开始的其他后台请求不追溯撤回，因此提交前需等待其他设置操作结束，并确认未保存编辑可以丢弃。

密码输入不保留到浏览器存储或文件。离开安全页、退出、过期或成功后清空三项输入；请求中阻止切页/退出和重复提交。取消确认保留输入，服务端拒绝或网络异常后清空输入。若请求中断且不确定结果，请重新登录确认，优先使用新密码；不要根据页面未收到成功反馈推断保存失败。

当前密码错误不会立即退出当前会话；登录与修改共享每分钟5次错误尝试限制。成功修改原子替换本机凭据，仅保存加盐派生值，不创建可恢复的旧密码备份；现有配置备份/恢复也不修改后台密码。写入失败保留旧凭据与会话；凭据被外部修改或文件异常时拒绝覆盖，按维护说明检查后重新启动。

验收：在页面查看入口和输入校验；只有准备好记录新密码时才实际提交修改，再验证新密码登录及旧会话失效。自动测试使用临时后台与合成密码，不修改日常密码。不在聊天中发送密码。
