# DeepSeek 识图配置与使用

识图配置为`ImageType=OpenAI`、`ImageAPI=https://api.deepseek.com/chat/completions`、`ImageModelName=deepseek-flash`，使用已经保存的同一DeepSeek密钥。密钥只在本机内部复制到独立识图字段，不输出到聊天或记录；以后修改聊天密钥不会自动同步识图密钥。保存前备份，其他全局AI字段、人物设定、群/私聊参数、插件及权限保持。

## 使用

在已启用Agent且有效响应的会话中，同时发送QQ图片与文字提问；群聊按已有@规则@机器人，主人私聊直接发送图片加提问。例如“请描述图片里有哪些形状和颜色”。图片须是QQ消息中的实际图片段，不是本机文件路径文字。

现有流程先用识图模型生成简短中文图片描述，再将描述送入Agent上下文，由Agent回答提问；不是将所有历史图片直接交给最终动作模型。普通`/gpt`及纯文字聊天保持现有文字接口，本次不新增`/gpt`图片处理，也不改群开关、角色白名单或语音输出。

QQ图片通过可读取的HTTP/HTTPS地址或消息base64数据加载；本机路径不读取。程序把图片缩放至最多1024×1024，再发送给模型，并使用相似图描述缓存。因此较小文字/图表细节可能丢失，不保证精确OCR；单独无文字图片可能被现有触发条件忽略。识图请求可能产生服务商图片与文本计费，图片内容会提交给DeepSeek。该流程只在Agent实际触发时运行，不批量导出聊天图库。

在后台“AI设置”检查识图字段即可；基础检查通过只说明已配置，不能代替实际模型识图和QQ验收。首次配置采用停止ZeroBot、核对备份及只改四个识图字段、重新启动的流程；不重启NapCat或重置对话档案。以后后台保存后，后续请求使用新设置。
