# 日志导出与验证

后台运行日志页新增“导出筛选日志”。使用已点击“应用筛选”的级别与关键词，从本次启动的内存缓冲区取得快照并下载 UTF-8 文本。导出最多 1000 条，按旧到新排列，不受页面首批 200 条限制，也不读取历史 stderr 文件。仍受原 1MiB 消息内容保留容量限制，因此长日志较多时可能不足 1000 条。

文件开头说明保留与匹配条数、是否已淘汰旧记录，以及截断/重启边界。每条日志占一行，正文使用引号包围并转义换行、引号等字符；中文和 emoji 保留为 UTF-8。文件名只含固定前缀及 UTC 时间，不包含关键词、配置地址或用户输入。空筛选结果仍可下载有说明的文本。

`GET /api/logs/export` 沿用后台的认证、回环 Host/Origin 检查和 `no-store`，返回 `text/plain; charset=utf-8`、安全附件名及 `nosniff`。当前接受单个 `level`、`q`、`from` 和 `until`（时间筛选于10月9日加入），拒绝路径、游标、条数及重复参数。导出前刷新已保存和运行配置的密钥，重新对旧记录脱敏；配置不可读返回 503，未接入日志返回 409，错误响应不会成为下载文件。

页面使用已应用条件，导出期间禁止重复点击；暂停更新时可导出。切页、隐藏、重新加载、改筛选及退出取消请求，过期响应不能生成文件。下载完成释放临时 Blob URL；响应格式、文件名及 3MiB 接收上限校验失败时不下载。导出只读取日志与配置，不修改日常配置或新增服务器端导出文件。
