## 实际使用

要按群控制，先由主人私聊机器人发送 `/全局沉默`，移除全局响应覆盖，再在目标群 @ 机器人发送 `/响应` 或 `/沉默`。已有显式响应的其他群仍保持响应；这不是强制所有群沉默。

响应门控和插件开关分别生效。若 sleepmanage 为显式禁用，`/响应` 不会启用它；需先在后台启用插件。“早安”还限制本机时间为 6～12 点，“晚安”为 21 点至凌晨 3 点。因此使用这些指令测试时须同时满足插件状态与时间条件。
