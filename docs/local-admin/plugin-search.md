# 插件搜索与状态筛选

登录本机后台，在“插件管理”先选择全局或指定群范围。搜索框匹配插件名称、功能简介和注册用法，例如输入 `/gpt` 可查找包含该指令说明的插件；搜索忽略大小写与首尾空白，按连续文字匹配。

“生效状态”可以选择全部、启用、禁用或状态未知，与搜索同时生效。状态取自当前范围最后一次成功读取或保存的实际结果，遵守全局覆盖、群设置、默认值顺序；未取得控制状态时归入未知，不把启动默认值当成实际状态。计数展示匹配数量、注册总数和当前范围的启用/禁用/未知数量。

搜索和筛选只调整显示，不保存开关。切换筛选、清除筛选后，已选择但未保存的开关仍保留；只有点击该插件的“保存开关”才写入并备份。保存后以新实际状态重新筛选，因此卡片可能从当前列表消失。“清除筛选”只清空搜索并切回全部；刷新或切换范围先确认丢弃，取消/读取失败保留原选择；成功读取才清除，详见 [插件编辑保护](plugin-drafts.md)。

无匹配时调整关键词或清除筛选。当前程序未注册插件时明确显示空列表。筛选不增加插件，不改变命令权限、群响应或 AI 模式；用法通过原“查看用法”入口完整查看。退出后台会清空搜索和筛选。

## 本机部署

刷新后台后，在插件管理搜索 /gpt，再组合启用/禁用条件，并核对当前范围的计数；切换筛选和清除后检查未保存开关选择仍保留。用户已确认该功能正常并验收。

搜索结果支持按名称、实际状态或未保存优先排序后分页，详见 [插件列表排序](plugin-sort.md)。

插件列表可下载当前已加载全局/群范围的全部匹配状态清单，沿用筛选与排序，草稿只标记未保存；仅导出最近已知插件开关状态，不能导入或恢复，见 [下载插件状态清单](plugin-state-catalog.md)。
