# 模型回复与资源联合核对

维护者运行`node scripts/check-combined-observation.mjs --resource 资源目录 --model 模型报告.json --before 起始回复快照.json --after 结束回复快照.json --output 尚不存在的结果.json`，一次检查已保存的模型、回复和资源资料。需要Node.js及输入读取权限，不需要后台密码或浏览器；无需部署或重启服务。

工具复用[模型与资源核对](observation-evidence-check.md)和[回复窗口核对](qq-reply-evidence.md)，验证原始资源样本、累计统计、时间和进程。除此之外，检查两次资源读取的原件摘要一致，并要求模型与回复窗口有正长度的交集。两个窗口分别有效、分别落在资源范围内，但互不重叠时，不能合并为同一段观察。

模型HTTP次数和回复任务数分别列出，不要求相等：Agent可调用多次模型或识图接口，一次任务也可发送多条回复。两种累计平均/最长保持原口径，不转换为窗口耗时、同批成功率或QQ客户端收到时间。身份、资源通过、时间范围和业务验收分别判断。

退出0表示三类资料内部有效、资源检查和精确进程关联通过，模型与回复观察窗口都有有效时间且重叠。退出2表示资料有效但条件不足，如短资源窗口、没有进程身份、窗口不重合或不同进程；退出1表示输入/配对/摘要无效、读取过程中资源原件改变、参数或输出失败。`businessAcceptancePassed=false`始终保留，不依据数字增长或联合核对通过关闭真实业务待办。

输出仅复制各工具验证过的固定字段、各来源摘要和联合检查结果；不复制附加的正文、QQ账号、配置、密钥或程序路径。输入大小和样本量沿用原核对工具的限制。省略`--output`只打印结果，输出文件必须尚不存在；不会覆盖原件或已有结果，不访问网络、原始日志、凭据或运行服务。
