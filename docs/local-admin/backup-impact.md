# 恢复预览的类别影响对比

登录本机后台进入“备份恢复”，选择有效备份并点击“预览恢复”。“类别影响对比”显示当前保存状态与备份的类别差异，标签区分“有变化”和“一致”，有数量信息时显示当前与备份数量。预览只读，不自动恢复、备份、修改开关或重启。

启动配置分为正向连接、反向连接、机器人主人、其他机器人参数、其他启动设置。连接或账号按条数对比，其他设置按所属对象字段数对比；同样数量可能有不同内容，需同时查看变化标签。字段名称、地址、Token、主人QQ和其他配置值不在该摘要中展示。仅字段名称大小写或其他表示有区别时可能另列“字段名称或表示差异”，沿用原JSON一致性判断。

后台选项分别比较后台启用状态与访问地址，只显示是否有变化。控制库按响应规则与AI扩展、全局用户封禁、插件开关继承标记、插件与其他库内数据四类汇总记录数量与内容变化；不展示表名、用户/群号、模型密钥、提示词或原始行。只有当前库与备份结构一致且原完整性检查通过时才提供预览。

摘要使用预览时的同一份当前状态及已校验备份生成；不是仅恢复变化类别的选择器，实际恢复仍覆盖整个所选范围。保留原范围警告、勾选确认、10分钟预览有效期、修改后重新预览、写前备份和冲突保护。配置与备份相同则恢复按钮仍不可用；预览取消/失败、刷新、切换后台页面、退出或操作时发现预览过期会清空旧摘要，迟到结果不能回填新会话。

验收：预览不同范围，核对类别、数量和标签，再取消，不需使用日常配置演练恢复。真实恢复完整页面操作仍按TODO-BACKUP-01保留；差异、缺字段、密钥变化、数量相同内容不同与冲突保护由隔离测试覆盖。

验证：4项新增Go、86项界面、64项布局和22:16:44完整Windows隔离回归通过。三种备份范围均覆盖相同数量但内容不同、完整性/认证与旧快照保护；无密钥或原始内容返回。取消、失败、刷新、导航、过期操作和迟到结果清理验证通过。本机新资源、原认证、正确账号与OneBot正常；启动配置、控制库和日常凭据保持，NapCat未重启。证据见 [自测记录](self-test.md)。
