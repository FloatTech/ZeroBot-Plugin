# 日志起止时间筛选

登录本机后台进入“运行日志”，填写开始时间、结束时间并点击“应用筛选”。时间使用当前浏览器的本地时区，精确到秒；可只填写一端，留空不限制该端。边界包含所填时刻，开始不能晚于结束。时间与级别、关键词同时筛选脱敏后的保留日志。

输入修改不会立即改变已应用条件；状态栏显示查看和导出的实际范围。无效或倒置范围不能应用，已有结果和已应用条件保留。“只看异常”保留已应用关键词和时间；“清除筛选”清空全部条件；概览“查看异常日志”进入全部时间的异常记录。

暂停时可应用范围，恢复后读取；切换页面保留范围与未提交输入，退出或会话过期重置。重新加载沿用已应用条件，旧请求不能覆盖新范围。导出使用同一组已应用条件，文件列出实际UTC时间边界；没有匹配记录仍可下载说明文件。

只查询本次启动仍保留的日志，最多1000条、总容量1MiB；首次页面查询显示最新最多200条匹配记录，导出包含保留范围内全部匹配记录。时间筛选不会恢复已淘汰或重启前的日志，也不会改变日志保留容量。填写固定结束时间后，超过结束时刻的新记录不会进入结果。无需保存配置、重启机器人或修改QQ登录。

验收：在有日志的时段设置起止范围，应用后核对时间；修改时间但不应用，再下载核对仍是原范围；测试只填一端、开始晚于结束、暂停后应用及清除筛选。真实QQ与模型调用无需用于本项验收。
