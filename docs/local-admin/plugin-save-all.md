# 逐项保存全部插件草稿

登录本机后台，进入“插件列表”，先选择全局或指定群并读取。修改多个开关后，点击“逐项保存全部草稿”，确认当前已读取范围、总数量以及包含其他页和筛选隐藏项。按当前插件列表顺序提交全部待保存选择。显式全局设置覆盖所有群与私聊；继承模式沿用原默认/群级优先规则，群设置仍受显式全局优先级约束。成功后规则立即更新，不需要重启。

此入口逐项调用原保存接口，每个实际变更沿用自己的版本检查和写前备份，不是一次事务，也不统一回滚。每项确认成功才清除对应草稿，并更新实际状态与进度；遇到首次冲突、接口/网络失败或无法核对的返回结果就停止，不发送剩余项。已确认成功的规则保持，失败/未尝试草稿保留。单项请求设定30秒超时，超时会中断等待并停止余下项。网络失败或超时不推断该项未写入，也不自动重试；先记录余下选择并刷新状态核对，版本冲突按原规则处理。

保存中禁用范围切换、刷新、单项保存、草稿更改、分页与再次批量操作；搜索仍可查看，不改变已确认的保存目标。可切换后台页面，保存继续运行。点击“停止后续保存”后等待当前请求结束，停止尚未提交的项，不取消或撤销当前项；若当前项是最后一项并全部成功，显示全部完成。已保存的开关不能通过“放弃全部更改”撤销。

没有草稿、未登录或控制不可用时不能启动。确认期间范围、草稿或会话变化不得提交旧确认；退出/会话过期清空批次和状态，迟到响应不能更新新会话或继续发请求。关闭浏览器或页面刷新不会自动续跑；离开提醒受浏览器限制，已提交项需要重新登录后核对。草稿和执行进度只在当前页面内存，不写浏览器存储。

验收可先修改两项但不保存，核对按钮、确认范围/数量与隐藏项说明，然后取消并放弃草稿；无需改变日常开关。完整执行、失败、停止与会话场景由隔离 Chrome 和临时 Windows 程序验证。真实 QQ 完整业务保持原待办。

自动化用例：scripts/test-plugin-save-all-ui.mjs 新增6项隔离 Chrome 场景，覆盖全局/群、隐藏项、逐项确认、失败、停止、超时和旧会话；全部界面回归共108项及64项布局通过，模块测试与静态检查通过。实际 Windows 接口逐项保存与备份、冲突后部分结果和无变化不备份由 scripts/smoke-local-admin.go 验证，15:24:25完整 Windows 回归通过，15:26:18本机部署通过，原配置/开关/后台凭据和 NapCat 登录保持。结果与部署证据见 [自测记录](self-test.md)。

插件列表可下载当前已加载全局/群范围的全部匹配状态清单，沿用筛选与排序，草稿只标记未保存；仅导出最近已知插件开关状态，不能导入或恢复，见 [下载插件状态清单](plugin-state-catalog.md)。
