# 插件用法复制与下载

登录本机后台，在“插件列表”找到插件并点击“查看用法”。窗口中的“复制用法”和“下载文本”使用打开时的快照：复制为注册用法原文，下载附插件名称、简介和注册用法；搜索、翻页或开关草稿不改变导出内容。注册用法为空时显示缺失提示，两个按钮禁用。

复制由点击按钮触发，浏览器须支持剪贴板写入。复制失败或不可用时，页面选中用法文本，按 Ctrl+C 手动复制（浏览器可能省略末尾空换行），或者下载文本；不会显示系统错误细节或反复申请权限。复制执行中禁止重复复制，关闭窗口或退出后不显示迟到结果；已经发起的剪贴板写入无法撤回。

下载生成 UTF-8 文本文件，保留中文、换行和 emoji；文件名以 zerobot-plugin- 开头，清理非法文件名字符并限制长度。下载内容只包括打开时的插件名称、简介和注册用法，不包括群号、生效状态、Token、模型密钥、后台配置或聊天历史。它是注册说明原文，不是从代码推导的完整手册；说明缺失或过时需维护插件自身文档。

仅当前已登录后台可使用，不调用新的服务端接口、不修改机器人规则或创建配置备份。关闭窗口、Escape、退出或会话过期清空内容与提示，重新打开其他插件采用新快照。下载及复制不会执行说明中的 QQ 指令。

验收：选择有中文/多行说明的插件，复制后粘贴到自己的文本编辑器，或下载后打开核对名称、简介和用法。无说明插件的按钮应禁用；关闭再打开另一插件不残留前一个的提示。浏览器下载目录及剪贴板由浏览器管理，已下载文件不会随退出后台被删除。
