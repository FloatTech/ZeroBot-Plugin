# 清空当前显示的日志

使用后台密码登录本机管理页，进入“运行日志”。已有记录时点击“清空当前显示”，立即移除本页已显示的日志及复制提示，不删除服务端保留记录或日志文件，不发送请求。没有记录、读取处理中、未登录、切到其他页面或窗口隐藏时按钮不可用。

清空后保留已应用的级别、关键词、时间范围及未应用输入，保留暂停/持续更新与自动滚动选择、当前实例和增量游标，不停止或增加轮询。持续更新时下次按原游标读取新记录；暂停时可用“读取一次”或“恢复更新”。清空时刻不等于新日志时间起点，先前尚未读到的记录仍可能随后出现，原断档/重启和容量限制保持。

匹配统计仍是最近成功读取时服务保留范围的统计，不按清空后的页面条数归零；导出仍包含已应用条件下服务保留的日志，包括本页刚清空的记录。需要再次查看近期记录时点击“重新加载日志”；暂停状态下重新加载只重置读取位置，仍需读取一次或恢复更新。更早超出服务保留范围的记录不能恢复。

清空操作没有撤销按钮，仅影响页面显示。页面会持续提示此范围，切换后台页面再回来保留；重新加载、应用筛选、成功识别新实例或退出/过期/恢复重置后清除提示。不会显示被清空的正文或字段值。日志正文的手动复制选区随清空移除，页面其他位置的选区保留；迟到的剪贴板结果不能重新选中或覆盖新记录。正在进行的导出按原规则完成，不受清空影响。

验收：暂停并读取记录，点击清空，核对记录消失、匹配统计和筛选保持；读取一次可显示后续记录，重新加载后读取一次可重新查看近期保留日志。无须发送真实 QQ 消息、修改配置或清理备份。
