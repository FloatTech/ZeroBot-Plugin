# 插件开关编辑保护

登录本机后台，打开“插件列表”，读取全局或指定群的插件状态后，选择开关模式。尚未点击“保存开关”的选择属于草稿，不改变实际生效状态。

页面显示当前范围和未保存插件数量，每张有改动的卡片显示“未保存”。改回读取时的模式会清除该插件的标记。搜索、状态筛选和切换后台页面保留草稿，包括筛选后暂时看不到的插件。

“刷新插件状态”、读取其他群和退出登录会先提示丢弃未保存选择；取消不发出请求。确认刷新或切换后，只有成功读取才替换列表和清除草稿，失败保留原范围与选择。各插件可单独保存，也可 [逐项保存全部草稿](plugin-save-all.md)，每项确认成功只清除对应草稿；冲突和写入失败保留选择，重新读取后再核对最新状态。

保存或读取过程中禁用开关操作，退出提示等待。关闭或刷新浏览器时，请求未结束或有未保存选择会请求浏览器显示原生离开提醒；是否显示取决于浏览器和用户交互状态。

草稿只存在页面内存中，不写浏览器存储。退出成功或会话过期后清空列表、群号及草稿；旧会话的迟到读取/保存结果不会影响新登录的页面。已提交的服务器写入不因客户端会话过期而撤销，应重新读取确认。

权限、全局覆盖优先级、群内 @ 规则、生效方式和写前备份保持现有行为。使用后台需要本机后台登录；保存后立即影响后续消息。

验收步骤：改动两个插件，筛选隐藏其中一个，再取消刷新/切群/退出，确认选择保留；改回原值确认标记减少；只保存一个确认另一个仍未保存；确认重新加载后核对实际状态。日常状态不用于故障演练，读取失败、冲突和旧会话竞态由隔离测试覆盖。
