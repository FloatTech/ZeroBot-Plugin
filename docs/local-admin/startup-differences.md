# 已保存配置与本次启动的差异摘要

登录本机后台，进入“连接设置”，读取成功后查看“启动配置差异”。按正向连接、反向连接、机器人主人、其他机器人参数、其他启动设置分类显示本次启动数量与已保存数量，以及一致或有变化；数量相同仍可能内容不同。字段名称或表示差异无法归入上述类别时单独提示。整体待重启结论沿用原完整 JSON 比较。

摘要比较最近一次成功读取或保存的配置文件与本次 ZeroBot 启动快照，不包含表单未保存草稿，不表示连接实时在线状态。编辑、切换连接或切页不会重新比较；成功读取、编辑保存、新增、删除或恢复后重新读取才更新。读取失败保留上次结果，需依据读取失败提示重新加载核对；退出或会话过期清空摘要，未使用启动配置文件时不展示。

摘要只显示固定类别、数量和变化状态，不展示 Token、密钥、未知字段名称、配置值或摘要哈希。同数量下更换 Token 也计为内容变化；修改并保存回本次启动相同配置后显示一致。这里只读，不执行重启、备份、恢复或 NapCat 设置。原保存、备份、版本与草稿保护保持。
