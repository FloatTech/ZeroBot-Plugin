# 删除已保存的 OneBot 连接

登录本机后台，进入“连接设置”，选择已保存的正向连接或反向监听，点击“预览删除当前连接”。核对类型、序号、已脱敏地址以及删除后的总连接数，勾选“我确认从已保存配置中删除这个连接”，点击“备份并删除连接”。预览与取消只操作本页，不发写请求；确认保存采用原版本校验、受限写前备份及原子替换。

删除只移除所选启动JSON连接项，保留其他连接、主人、未知字段和大整数，不立即断开、重启或修改NapCat登录。当前运行仍需要改变时重启ZeroBot后才生效；若只是删除尚未加载的新连接且恢复到本次启动配置，则提示无需为本次删除重启；需要恢复时从删除前的启动配置备份预览恢复整个启动配置。正向与反向合计至少保留一条，不能删除最后一条；无连接或未读取配置时不能删除。删除后同类型序号会调整，本次启动信息仍按原列表序号展示，不能将原序号与保存后的序号视为同一连接身份。

现有连接/主人或新增表单有未保存草稿时，先保存或放弃再预览删除。预览固定到当时读取的配置版本与所选项，换连接、编辑任何草稿、成功重读/保存、切换后台页面、取消、失败或退出会清空确认。请求中冻结页面切换、退出与其他连接操作；过期及迟到响应不能回填或解锁新会话。成功后重新读取后的相邻项被选中，展示写前备份和待重启提示。

错误或冲突时不声称删除成功，配置保留并清空删除确认；网络中断时无法判断是否已保存，先重新读取核对，再决定是否操作，避免按变化后的序号误删。普通接口、确认提示和错误不展示Token；预览地址沿用原脱敏显示。接口要求明确的类型、序号、确认与版本，删除不能与新增/编辑/主人修改混合提交。

验收可仅预览自己的连接再取消，检查目标和最后一条保护；隔离测试演练删除、备份恢复与启动快照加载，不使用日常连接执行破坏性测试。完整真实恢复及QQ业务仍按原待办范围记录。

自动化验证：新增4项Go覆盖正向/反向选定项移除、其他字段与精度/运行快照保留、删除前备份恢复和重开快照、明确序号/确认/互斥/最后一条/别名、写入/备份失败、并发与API认证；新增4项Chrome与原90项共94项界面、64项深浅色/窄屏布局通过。页面校验目标固定、文本显示、草稿/导航/取消/重读失效、无确认不提交、错误与迟到会话隔离；另覆盖删除未加载项而恢复到运行配置时无需重启的提示。未删除日常连接，实际体验另留待办。
