# AI回复统计快照下载

登录本机后台，在“运行概览”的“AI回复处理耗时”点击“下载回复统计”。先等待概览读取成功；读取中、统计缺失或无效、切页、隐藏标签和退出后不能下载旧快照。零任务仍可下载，表示本次启动尚无任务，不是业务验收成功。

按钮保存页面最近成功读取的累计快照，不重新请求接口，不保存配置，不发QQ消息或调用模型。正常使用前后可分别下载，并核对统计起点和可读取的进程编号、操作系统创建时间及程序摘要；重启前后的资料不得合并。刷新状态后再下载可取得新快照，文件内`checkedAt`标明读取时间。

文件格式为`zerobot-reply-statistics`版本1，文件名为`zerobot-reply-statistics-时间.json`。仅包含导出时间、固定范围说明及三类累计任务/发送确认/首末回复耗时、UTC时间和可读取的固定进程信息；不含正文、QQ账号、群号、消息编号、配置、程序路径或密钥。下载失败显示通用提示，可重新尝试；临时链接自动释放，连续点击在本次下载清理前被禁止。发起下载不代表浏览器已经保存文件。

快照没有观察起点或窗口统计。平均/最长值属于本次ZeroBot启动累计，不能将两份累计最长值相减得到窗口最长耗时，也不能把任务开始差值当作同一批任务成功率。进行中任务尚未计入首末回复平均；部分回复后失败的已结束任务可以进入平均分母，完整口径见[AI回复处理耗时](qq-reply-latency.md)。

固定范围声明为机器人匹配入口到当前会话发送回执，本次启动累计；业务验收字段始终为false。不能证明QQ客户端收到、已读或真实持续负载通过；现有[模型观察报告](model-observation-report.md)继续只记录模型HTTP传输，两种文件分开保存。本功能随新程序部署并仅重启ZeroBot生效，不改原AI触发或回复内容。
