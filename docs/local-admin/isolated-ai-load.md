# 独立AI持续负载观察

从仓库运行`./scripts/observe-isolated-ai.ps1 -BinaryName zerobot.exe`，使用指定测试构建的独立副本、合成OneBot及本地模拟模型，持续观察15分钟，每分钟一批3次GPT回复。记录Windows资源样本、模型快照和回复快照，自动调用现有离线核对工具检查同一进程及完整时间覆盖。需要本机Go、Node.js、PowerShell 7.5或更新版本（保留JSON原始时间字符串）和查询测试进程/运行回环实例的权限，不需要日常后台密码或Chrome连接。

工具只操作本次临时实例，不读取日常凭据、修改日常配置或启停日常ZeroBot/NapCat。模型默认人为等待150毫秒，用于验证计时包含等待；所有消息和模型请求均为本地模拟，不接入真实QQ或真实模型。结果不替代真实业务负载、其他权限角色、QQ客户端收到或端到端延迟验收。

产物在`.local/ai-load-observation/`的独立目录，包含原始资源样本/最终结果、前后回复文件、模型观察文件和两种核对结果，以及模拟批次数/请求数和清理结果。累计平均/最长保持本次启动口径，不计算窗口最长；前后业务次数只能对应本次合成GPT任务，不扩大为所有插件或真实用户场景。

快照由模拟驱动的认证接口生成，文件采用既有固定格式，不是浏览器下载原件。资源记录的零QQ/模型发送字段只说明被动采样部分没有发起这些动作；独立负载部分的合成请求数量在总结果另列，真实QQ和真实模型始终为0。此工具只测Windows程序及本地模型/发送确认链路，没有浏览器渲染或网络服务性能测量。

默认正式窗口900秒、资源间隔5秒、批次间隔60秒；可将持续时长设为10～1200秒、资源间隔1～30秒、批次间隔60～120秒，模型等待设为0～2000毫秒。少于900秒仅诊断，即使回复正常也不能算正式观察通过。开始/结束快照留在实际资源首末样本内，单次输入最多20批，不使用重复会话绕过日常限速。

采样前检查复制程序、进程编号/创建时间/摘要和本次模拟目录；每批沿用原模拟驱动对OneBot和模型地址的守卫。改变地址或目标、异常回执/统计、进程变化、采样节奏不足或资源检查不通过会记录失败，不拼接新进程。文件只保存固定统计字段和脱敏日志计数，不保存聊天正文、密钥或账号。
