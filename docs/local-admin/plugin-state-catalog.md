# 下载插件状态清单

登录本机后台，进入“插件列表”，成功读取全局或指定群范围后，点击“下载插件状态清单”。可先按关键词、生效状态、只看未保存筛选并选择排序。清单包含全部已加载匹配插件，不局限于当前分页；空结果也可下载，文件按浏览器下载设置保存。

导出UTF-8 JSON，记录实际已加载的全局/群范围、最近成功读取时间、最近成功保存开关时间、导出时间及加载/匹配/未保存数量。群号取自成功加载的范围；未提交的范围输入不会改变清单目标。文件标记是否使用最近读取失败前的结果，采用固定的筛选与排序字段；关键词只记录是否应用，不写搜索文字。

每项只列插件注册名称、启动默认值、最近成功读取或保存后的默认值/全局与群设置/生效状态/来源，以及是否存在本地未保存更改。状态未知明确列为unknown或null，不以启动默认推断；不导出草稿选择、开关版本、配置扩展、模型密钥、Token、简介或注册用法。草稿标记不表示开关已生效。“当前生效”仅指插件开关，不保证群响应、权限、限速及其他命令条件通过。

清单来自浏览器已加载状态，可能已被QQ指令或其他页面修改，不能当作服务端实时或所有插件一致时刻的快照。保存单项后只有对应项更新，最近保存时间不表示其他项重新读取。核对最新状态请先“刷新插件状态”；取消或读取失败保留原范围与草稿，清单仍使用原范围并标记读取失败。

未登录、未成功读取、读取或保存处理中、切离插件页或隐藏页面时禁止下载；退出、会话过期或恢复配置后清空清单来源，须重新读取，迟到请求不能回填新会话。下载不发额外接口请求、不保存或放弃草稿、不改变当前分页和用法窗口、不创建备份、不调整插件开关或调用QQ/模型。提示“已发起下载”表示浏览器开始处理，不保证文件已保存；失败可检查下载设置后重试。

文件仅供核对，不能用来导入或恢复开关配置。实际页面体验待验收；自动化使用合成插件和模拟接口，无需改变日常群开关或发送真实QQ消息。
