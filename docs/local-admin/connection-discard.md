# 连接设置局部放弃更改

登录本机后台进入“连接设置”，读取配置后，在保存按钮上方选择“放弃当前连接更改”或“放弃主人账号更改”。仅在相应部分存在未保存输入时可用。操作先确认，取消保留全部编辑；确认后只恢复这一部分最近读取或保存成功的值，另一部分草稿保持。

放弃当前连接时，以当前实际加载的连接为准，恢复其地址，清空新Token输入，动作回到保留，隐藏并取消清除确认；连接选择与主人账号草稿保持。放弃主人账号时，恢复已读取的主人QQ列表，保留连接地址、Token新输入及替换/清除确认选择。有多条连接时不影响其他连接；没有可编辑连接时当前连接撤销禁用，主人账号仍可按可用配置独立撤销。

操作仅恢复页面输入，不发送请求、不创建备份、不修改已保存配置、当前运行连接或QQ登录；已保存但待重启的提示继续显示。撤销结果另行提示，不会覆盖保存/待重启状态。已保存成功的更改不能通过此按钮回退。版本冲突后，撤销只恢复上次读取的值，需要重新加载配置获取最新规则。

请求中、未读取配置、无相应草稿或无可用配置时禁止操作。退出/会话过期清空输入，旧确认不能恢复新登录或新加载目标；原切换连接/重新加载/退出确认、固定目标保存、写前备份与需重启生效规则不变。草稿只在页面内存，不写浏览器存储或文件，提示和确认不展示Token。

验收：修改地址/Token动作与主人账号但不保存，分别先取消再确认放弃一部分，核对另一部分草稿保持；Token测试使用合成文字。若已保存配置待重启，确认局部放弃后提示仍在。不需为验收保存日常配置、改变主人或重启NapCat，保存/冲突/旧会话场景由隔离测试覆盖。
