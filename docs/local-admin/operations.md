# 本地服务运行与恢复

机器人登录账号与机器人主人分别配置；后台采用独立密码。首次安装、编译与资源初始化见[Windows环境](onebot-windows.md)和[使用指南](user-guide.md)。

## 持续运行方式

本地服务使用 Windows 计划任务服务启动独立宿主，避免依附于临时开发工具进程。

任务名称为 `ZeroBot-Local-<项目路径摘要>-OneBot/ZeroBot`，以当前已登录用户运行，权限为 Limited，手动触发，运行时限不限。没有添加开机或登录触发器。任务定义检查、PID、日志及清理入口都保留在项目中。

在项目根目录执行：

```powershell
# 启动 NapCat，页面就绪后按 expectedQQ 登录
.\scripts\start-local-services.ps1 -Service OneBot

# 登录正确账号后：检查认证、账号及三个只读 API
.\scripts\test-onebot.ps1

# 验证正确账号后启动 ZeroBot 的独立宿主
.\scripts\start-local-services.ps1 -Service ZeroBot

# 停止本项目托管服务；All 先停 ZeroBot，再停 OneBot
.\scripts\stop-local-services.ps1

# 不再使用时停止并移除本项目任务，可用启动脚本重新创建
.\scripts\stop-local-services.ps1 -Unregister
```

任务名称记录在 `.local/services/tasks.json`，宿主日志位于 `.local/services/`。真实进程信息仍分别写入 `.local/onebot/runtime/process.json` 和 `.local/zerobot/process.json`。停止脚本先校验任务定义、程序路径和进程启动时间，再结束对应进程树及任务，避免只停宿主而留下机器人。ZeroBot 停止、更新程序及重启已实际通过；OneBot 停止及任务移除尚未实测。

## 连接设置与保存

刷新 `http://127.0.0.1:3010/` 并重新登录后，从左侧进入“连接设置”。现可编辑已有正向连接或反向监听，也可 [新增正向连接](connection-add.md)、[新增本机反向监听](reverse-connection.md) 或 [删除连接](connection-delete.md)。删除至少保留一条连接，须核对固定预览目标并确认；新增、修改、删除均在保存前备份，重启后加载。

1. 选择连接，修改 WebSocket 地址（`ws://` 或 `wss://`）。不修改地址时完整保留原值；带认证参数的旧地址只展示脱敏值，替换地址时请使用独立 Token 字段。
2. Token 默认为“保留当前 Token”，无需输入；替换时输入新值，清除时选择“清除 Token”并勾选确认。读接口不会返回当前 Token。
3. 主人 QQ 账号用空格或逗号分隔，至少保留一个；这是管理者账号，与 NapCat 登录的机器人账号不同。
4. 点击“备份并保存配置”。每次实际修改先备份旧启动配置，再替换文件；无修改时不写入、不生成重复备份。页面显示本次启动值和已保存值，修改后提示“待重启”。发生版本冲突时先重新加载，再核对更改，不直接覆盖。

页面只写 ZeroBot 的 `-c` 配置文件。本机文件为 `.local/config.json`。NapCat 的地址/Token 不会自动同步，变更连接前须确保两端匹配；保存后需按上文脚本停止并重新启动 ZeroBot。现有启动脚本会检查 NapCat 登录账号及配置配对，配对不符时拒绝启动。

启动配置备份位于 `.local/admin/backups/`，是含版本、时间和 `startup-config` 范围的 JSON 封装，旧启动配置在 `config` 字段，不能直接传给 `-c`。备份可能含 Token，使用当前 Windows 用户与 SYSTEM 的受限权限，不公开正文下载，也不进入 Git。“备份恢复”现有列表、手动创建、预览恢复和手动清理；另提供控制数据库及后台选项两个独立范围。启动配置备份不包含数据库，控制库备份也不等于全部插件数据库或聊天/媒体备份。详见下文恢复操作与 [备份范围说明](backup-restore-2026-10-02.md)。

后台写入串行化并检查版本；也会在写前重新检查文件，但不能与任意外部编辑器建立共同锁。保存期间避免同时用其他工具编辑同一个配置文件。连接页面的运行值表示本次启动快照；插件开关即时更新见下节，AI 设置见末节。测试范围及限制见 [连接设置验证](connection-settings-2026-10-01.md)。

## 插件管理

1. 默认查看全局。每张卡片展示当前生效状态、来源和当前默认值；从下拉框选择“显式启用”“显式禁用”或“继承默认”，点击“保存开关”。显式全局设置覆盖所有群及私聊。
2. 管理某群时，范围选择“指定群”，填写正整数群号，点击“查看此范围”。卡片下拉框展示此群保存的设置，状态徽标展示最终生效结果；全局覆盖存在时，群设置虽可保存，但不决定最终状态。
3. 要让各群独立决定，先将全局设为“继承默认”；群的“继承全局或默认”会移除此群显式覆盖，同时保留插件已有参数。群号须自行核对，当前没有 QQ 群自动下拉列表；不修改群沉默、黑名单或个人封禁规则。
4. 保存成功立即更新运行规则，无需重启；聊天命令修改后刷新状态也可看到结果。旧页面提交遇到冲突时重新加载后核对。刷新状态或切换范围先确认丢弃尚未保存的选择，取消或读取失败保留原选择，运行概览的十秒自动刷新不会覆盖插件选择。

每次实际开关修改或默认翻转前，网页和聊天指令均创建控制数据库快照；无修改不重复创建。备份仍在 `.local/admin/backups/`，目录名以 `-control` 结尾，含 `plugins.sqlite` 与 `manifest.json`。使用 SQLite 一致性快照，涵盖当时控制库里的开关、群参数及 AI 扩展数据，可能含模型密钥；权限仅当前用户和 SYSTEM，不公开下载、不进入 Git。备份失败则拒绝该次开关修改。批量聊天开关是逐插件执行，有失败会明确报告未全部完成。

控制库的手动快照可运行 `go run scripts/backup-control.go`（需要现有数据库），也可使用后台“备份恢复”的列表、手动备份、预览与确认恢复。AI 扩展/群参数、响应/沉默、用户封禁/解封及插件禁止/允许均已接入写前备份；业务计数不逐次备份。旧备份通过下述手动清理入口处理。网页不发送启停 QQ 通知，也不调用需要聊天上下文的启停回复回调。

控制依赖补丁新增继承元数据，回退到旧二进制前需考虑数据库兼容；不能把仅替换旧程序当成完整配置恢复。具体改动及验证见 [插件管理验证](plugin-management-2026-10-02.md)。

## 群响应与插件开关

插件管理的搜索包含名称、简介和注册用法，例如 `/gpt`；“生效状态”按当前所选全局/群范围的实际启用、禁用或未知结果筛选。筛选和清除不会写配置或丢失开关草稿；保存后按新实际状态重算，卡片可能消失。刷新或切换范围先确认丢弃，成功读取才清除草稿，退出会重置检索条件，详见 [插件搜索与筛选](plugin-search.md)。

AI 页面有独立编辑保护：全局与群参数分别标记未保存更改，切换后台页面保留草稿，重新加载/切群/退出先确认；取消、读取失败或保存冲突保留编辑，成功保存只清除对应表单。保存进行中先等待结果；会话过期立即清空表单，旧响应不覆盖新会话。草稿不写浏览器存储，刷新/关闭提醒受浏览器限制，详见 [AI 编辑保护](ai-drafts.md)。

`/全局响应`、`/全局沉默` 仍仅限机器人主人：推荐私聊发送；群里使用时仍需 @。全局响应开启后覆盖各群响应门控。按群控制前，先私聊 `/全局沉默` 移除全局覆盖，再在目标群 @ 机器人并发送 `/响应`；其他已显式响应的群保持原值。

插件开关和响应门控分别生效。`/响应` 不会重新启用被禁用的 sleepmanage；该插件“早安”仅在本机时间 6～12 点响应，“晚安”为 21 点至凌晨 3 点。验证经过与范围见 [群响应修复](response-command-fix-2026-10-02.md)。

## AI 设置

刷新 [本机后台](http://127.0.0.1:3010/)，登录后选择左侧“AI 设置”。原有配置会直接读取，无需重新输入已保存密钥。

1. 填写模型提供方要求的完整请求地址、接口类型和模型名。例如 OpenAI 兼容服务通常需要完整的聊天请求路径；填写提供方的实际地址。密钥保持默认“保留”，替换时在后台输入新值，清除时选择并勾选确认。密码与密钥无需发到聊天中。
2. 根据需要修改系统提示词、TopP 和最大输出长度，点击“备份并保存全局配置”。后续请求生效；普通聊天中已发出的请求继续使用旧快照，Agent 旧任务在后续请求/动作前检查配置版本并停止，重新创建实例后保留历史。
3. 选择“指定群”或“指定私聊”，填写群号或用户 QQ，点击“查看会话参数”。聊天触发概率、温度、Agent/语音/响应 @ 开关，与 GPT/群总结温度分别保存。群参数不改变插件开关或响应门控，仍须满足原权限和启用规则。
4. 同时通过聊天指令修改设置后，重新加载即可看到最新值。遇到版本冲突先重新加载再核对；重新加载或切换群会提示未保存更改，确认后成功读取才替换表单；取消或读取失败保留编辑，详见 [AI 编辑保护](ai-drafts.md)。

温度 0 使用原默认 70（实际 0.7）；TopP 0 使用默认 0.9；最大长度 0 使用默认 4096。普通配置读取不返回密钥；旧地址中的认证信息隐藏显示，不修改就保留。每次实际修改先保存私有控制库快照，可能含模型密钥；备份失败会拒绝保存。

`/gpt 问题` 可直接发送，或回复一条消息后发送 `/gpt 问题`。必须有空白边界；`/gptabc` 和普通句子提及不触发 GPT。GPT 与群总结共享每群/私聊 30 秒一次的额度，失败尝试也计入本次窗口。聊天、上下文、系统提示词和回复文字会发给所配置模型；群总结发送所选消息的昵称和文字（最多 1000 条）。参数和验证范围见 [AI 设置记录](ai-settings-2026-10-02.md)。

主人可私聊发送 `/gpt 你好，请简短介绍自己` 验证实际回复；GPT/总结继续遵守 30 秒额度。Agent 需满足插件、响应及会话开关；普通成员的 Agent 权限表不允许发送私聊消息，主人可以，原群权限与 @ 条件未改变。

## 运行日志

刷新并重新登录后从左侧进入“运行日志”。选择日志级别、输入关键词并点击“应用筛选”；“暂停更新”停止读取，“恢复更新”继续。取消“自动滚动”可停留阅读，同时继续接收新记录。

显示本次启动后接入的近期日志，最多 1000 条；重启后清空，长记录显示截断提示。暂停或断线期间超出保留范围会提示部分旧日志不可读。切换到其他页面或隐藏窗口后停止读取；不需要长期保持页面打开。

认证信息、已配置密钥及收发消息正文隐藏显示；网页不读取历史 stderr 文件。日志中包含脚本或 HTML 时也只显示文字。不能读取配置时日志暂停提供并提示错误。完整范围及验证见 [日志查看记录](log-viewer-2026-10-02.md)。

点击“导出筛选日志”下载 UTF-8 `.txt` 文件。先点击“应用筛选”，再导出；尚未应用的输入不会影响文件。暂停更新时也可导出。文件按时间顺序包含本次启动仍保留、符合条件的日志，最多 1000 条，不受页面首批 200 条限制。开头说明保留与匹配条数、旧记录是否已淘汰；正文里的换行写成 `\n`，长记录继续保留截断提示。

导出时重新读取配置以保护最新密钥，配置读取失败则不提供文件。切页、隐藏窗口、退出、重新加载或改变已应用筛选会取消尚未完成的导出。实现与测试范围见 [日志导出记录](log-export-2026-10-02.md)。

## 备份恢复操作补充（2026-10-02）

后台“备份恢复”可分别保存和恢复完整启动 JSON、控制数据库、后台启用与地址设置。先预览范围，再勾选覆盖确认；恢复前自动保存当前状态。启动配置及后台地址需重启，控制层提交后立即刷新，但其他插件缓存可能也需要重启。网络中断时先检查当前配置和备份列表，不直接重复提交。

控制库备份包含密钥及库内插件数据，恢复会覆盖整个库；QQ 登录、后台密码、媒体和其他数据库不包含在内。恢复后台选项后若启用状态或端口改变，下次启动应按恢复后的地址访问。详细限制和验证见 [备份恢复记录](backup-restore-2026-10-02.md)，真实 AI 测试仍保留为 [待办](todo.md)。

启用后台时，聊天管理指令的实际响应/沉默、封禁/解封及插件禁止/允许修改也会自动建立控制库快照；重复操作不创建新快照。群内响应/沉默仍需 @ 和原管理权限。若备份或保存失败，会回复“原状态保留”，修复本机目录或数据库问题后再操作；批量指令按账号分别保存，可能部分成功，应按报告核对。备份目录继续使用后台的私有目录，业务计数不逐次备份，详见 [控制策略备份记录](control-policy-backups-2026-10-02.md)。

## 服务列表聊天记录

`/服务列表` 改为发送合并聊天记录，每页最多 20 个已注册插件，包含名称、功能简介、当前群/私聊开关与注册用法。私聊直接发送，群内仍需 @ 机器人；英文 `/service_list` 保留。用 `/服务列表 2` 翻页，非法或越界页码有提示。每个节点最多 1200 个 Unicode 字符，过长用法保留开头并提示 `/用法插件名` 查看完整说明；原用法指令和后台“查看用法”保留。

该命令只读，关闭的插件仍可查看；启用状态不代表所有成员都具有使用权限。记录发送者使用机器人账号，发送失败给出文字提示，不自动重发。用法来自注册说明，未提供时明确标注。用户已确认功能验收，说明见 [服务列表](service-list.md)。

## 运行概览中的近期异常

登录后台进入“运行概览”，查看当前连接与本次启动的近期异常。页面可见时每 10 秒刷新，也可点“刷新状态”；切页、隐藏或退出停止读取，回到页面重新获取。连接读取失败会清除旧在线账号显示，明确提示状态未取得。插件列表读取失败单独提示，不再使概览显示为连接异常。

异常统计只涵盖有界日志缓冲中仍保留的 warning/error/fatal/panic；最新 5 条按记录顺序倒序显示，内容继续脱敏。历史警告可能已经解决，也可能只是素材摘要服务器不可达；结合记录时间和当前运行状态判断，不以数量当作未解决故障数。配置暂不可读时不展示异常正文，OneBot 状态仍独立显示。完整日志筛选与导出在“运行日志”，说明见 [运行概览与近期异常](overview-alerts.md)。

## 清理旧备份

在“备份恢复”填写每类保留数量和保留天数，点击“预览清理清单”。默认每类保留最近 10 份，同时保留近 7 天的所有有效备份；只有同时超出两项保护的备份才列入删除清单。核对范围、时间、数量和空间，另存需要长期保留的内容后，勾选永久删除确认并执行。清理无需重启，不改变当前配置和 AI 对话档案，不会定时自动执行。

每批最多 100 份，预览 10 分钟有效；修改参数、切页、登录会话或有效备份清单变化后需要重新预览。损坏、无摘要、链接或多余文件的备份跳过。删除失败或请求中断时，先刷新检查实际状态；已删除的部分不能撤销，不要直接重试旧清单。范围和扫描限制见 [备份清理](backup-cleanup.md)。

## 外观与小屏窗口

登录页和后台顶栏均有“外观”选择，支持“跟随系统”“浅色”“深色”。默认跟随系统；明确选择浅色或深色后不再受系统变化影响。在相同站点的当前浏览器保存选择，重开页面或退出登录后仍保留，并同步到同站点的其他标签页。

浏览器禁用本地存储时仍能切换，但刷新后恢复跟随系统。外观不写机器人配置，不影响密钥、后台密码或插件开关。同一台电脑的不同浏览器和不同后台端口各自保存。

窄窗口下导航移到顶部并保留名称，表单与操作按钮按需换行；本机访问规则不变。测试范围和记录见 [主题与小屏验证](appearance-2026-10-03.md)。

## Agent 连续对话

Agent 开关按当前群或私聊分别保存。开启后，普通聊天触发优先使用 Agent；`/gpt` 和群聊总结继续走聊天接口，其他明确插件命令按原规则处理。Agent 没有产生可执行动作时可能回退普通聊天。模式切换、触发条件、权限与示例见 [使用指南](user-guide.md#普通聊天agent-与-gpt)。

`/gpt` 与群聊总结的最终文字回复，200 个 Unicode 字符以内（含 200）直接发送普通消息，超过 200 字发送合并聊天记录。标题、标点、空格和换行计入长度，中文和 emoji 按 Unicode 字符计算；长回复保留全部内容，每个记录节点最多 1000 字。这是 QQ 显示方式的调整，不是对上下文记录或模型输出长度的限制。

Agent 已取消固定对话/行动轮数限制，并将事件与动作结果保存至 `data/aichat/history/<机器人QQ>.sqlite`，首次事件时创建。修改人物设定和重启会保留历史；主人指令 `重置AI聊天Agent` 开启新上下文并保留旧档案。单次模型请求仍受上下文容量、输出设置和超时约束，重复动作会停止当前任务。对话档案不包含在后台配置备份中；文件备份和行为说明见 [Agent 连续对话记录](agent-history-2026-10-03.md)。

## 隔离系统自测

从仓库根目录执行 `CGO_ENABLED=0` 环境下的 `go run scripts/test-admin-system.go -mode restart`，可重复验证三类备份恢复后的实际 Windows 进程重启、后台端口/关闭、凭据保留和旧会话拒绝。脚本新建独立目录和模拟 OneBot，不把日常配置用于恢复演练，不要求 QQ 重新登录。

`go run scripts/test-admin-system.go -mode performance` 顺序运行四组持续性能测量，每组默认预热一分钟、采样五分钟，总运行时间约 25 分钟。结果位于 `.local/admin-system/`，只测机器人进程和后台接口，不包含浏览器渲染、真实模型或 Windows 计划任务。执行方式、结果和限制见 [Windows 系统验收](system-acceptance-2026-10-02.md)。

## AI 私聊参数

后台 AI 设置支持指定群与私聊用户 QQ。同号群和私聊分别保存，与聊天配置指令共用控制数据；私聊无群总结，不改变 Agent 权限、插件开关或全局模型。填写的是与机器人聊天的用户账号；保存目标由已读取表单标题确定，改变选择后必须点击查看才能加载新目标。取消切换或读取失败保留原编辑和保存目标。完整步骤见 [AI 会话参数](ai-conversations.md)。

## Windows 路径别名

本机 C 盘 Documents 下 ChatGPT 父目录联接到 D 盘，项目两种路径实际相同。统一以 D 盘实际目录记录新服务，旧 C 盘入口和任务继续兼容；启停脚本解析父目录联接，再核对真实工作目录、脚本、程序和启动时间。启动复用同项目运行任务，停止只操作完整身份匹配的服务；不要删除配置或联接来消除路径差异。详见 [Windows 服务路径](windows-paths.md)。

连接设置编辑保护：当前已加载连接决定保存目标，切换连接先确认未保存的地址/Token修改；主人账号属于整个配置，切换连接仍保留主人草稿。重新加载或退出确认所有编辑，成功读取才替换，失败保留原值与版本；保存/读取期间冻结表单。退出/会话过期/备份恢复成功清空编辑，旧请求不能回填新会话。Token 不显示在草稿提示，不写浏览器存储。步骤见 [连接编辑保护](connection-drafts.md)。

异常日志入口：概览“查看异常日志”切到日志的警告与错误组合，清空旧关键词；组合含warning/error/fatal/panic。日志“只看异常”保留已应用关键词，清除筛选恢复全部；输入未提交时提示“尚未应用”，轮询和导出继续采用已应用条件。快速切换取消旧请求、重置游标，保留暂停/滚动设置；只是级别筛选，不推断问题已解决。见 [异常日志筛选](log-issues.md)。

备份检索只查询已加载元数据，不读取或导出凭据内容。范围与校验状态可组合编号/日期关键词；旧版无摘要与损坏备份分别显示，后端恢复仍重新校验。过滤不更改当前恢复/清理确认目标，恢复预览编号可核对；条件跨页/刷新保留、退出清空，请求中禁用；刷新失败保留旧列表并标记。最新200份限制在计数说明中提示，见 [备份检索](backup-search.md)。

备份恢复页默认每页20份，可选择10或50份，以“上一页”“下一页”浏览筛选后的记录；列表位于清理表单之前。改变筛选或份数回首页，刷新保留当前页并在结果减少时校正；切页保留，退出重置。分页仍只涵盖已加载的最新200份，不改变恢复/清理目标，打开恢复预览自动定位到编号与确认处，见 [备份分页](backup-pagination.md)。

插件列表支持默认20个、可选10/50个分页；搜索和实际状态筛选覆盖全部已加载插件。翻页保留所有开关草稿，总数包含隐藏项；单项保存规则保持，读取成功换范围回首页，刷新/保存后校正页码。详见 [插件分页](plugin-pagination.md)。

插件列表可勾选“只看未保存”，结合搜索/实际状态集中查看全部页草稿；“清除筛选”取消该限制且保留草稿。“放弃全部更改”确认后撤销当前范围全部未保存选择，包含隐藏项，只清页面内存，不发请求或改变已生效规则。详见 [待保存插件开关](plugin-pending.md)。

AI设置各表单提供“放弃此表单更改”，确认后恢复该表单最近读取或保存成功的页面基线，保留其他表单草稿；全局恢复同时清空新密钥输入，动作回到保留。仅本页内存操作，不请求接口或回退已保存设置，见 [AI 按表单放弃更改](ai-discard.md)。

连接设置可分别“放弃当前连接更改”和“放弃主人账号更改”，确认后恢复选中部分的读取/保存基线，保留另一部分草稿；连接撤销清空新Token并回到保留。仅页面操作，不写配置，待重启提示保持，见 [连接设置局部放弃](connection-discard.md)。

运行日志支持按浏览器本地起止时间筛选，可留空一端；点击应用后查看与导出使用相同范围，倒置输入不能应用，见 [日志时间筛选](log-time-filter.md)。

后台密码修改入口为“后台安全”，成功后所有后台会话需重新登录，不修改QQ/OneBot/模型密钥；完整步骤与异常处理见 [修改后台密码](admin-password.md)。

## 日志快捷时间范围

运行日志页可立即应用最近15分钟、1小时或24小时，或用“不限时间”移除起止限制。范围固定到本机点击时刻，沿用已应用级别/关键词；查看、统计与导出一致，暂停状态保持，仍受本次启动日志保留上限约束。详见 [日志快捷时间范围](log-quick-range.md)。

插件列表支持默认顺序、名称、启用优先、禁用优先及未保存优先；排序覆盖全部匹配插件再分页，保留草稿，清除筛选保留排序，见 [插件列表排序](plugin-sort.md)。

插件卡片支持“放弃此项更改”，确认后只恢复此插件的页面基线，保留其他页和隐藏草稿；不会撤销已保存的规则，见 [放弃单个插件草稿](plugin-discard-one.md)。

备份恢复页可按时间从旧到新、大小从大到小或从小到大排序全部已加载匹配项；分页和下载清单沿用所选顺序，见 [备份列表排序](backup-sort.md)。

备份恢复页提供已加载/匹配和固定范围的备份内容大小摘要，异常大小单列；不代表目录实际占用，见 [备份内容大小](backup-size-summary.md)。

暂停日志更新时可点击“读取一次”，按已应用条件读取新日志和匹配统计，完成后仍保持暂停，见 [暂停时读取一次日志](log-read-once.md)。

备份列表可按本地开始/结束日期组合筛选，结束日期包含完整当天；列表、大小摘要与清单采用同一组已应用日期，清理策略和恢复目标保持，见 [备份日期筛选](backup-date-filter.md)。

插件列表可下载当前已加载全局/群范围的全部匹配状态清单，沿用筛选与排序，草稿只标记未保存；仅导出最近已知插件开关状态，不能导入或恢复，见 [下载插件状态清单](plugin-state-catalog.md)。

运行日志每条记录可点击“复制本条”，只复制页面已显示的时间、级别与脱敏正文，剪贴板受限时选中正文手动复制，详见 [复制本条日志](log-copy-entry.md)。

AI设置页会按表单汇总未保存字段名称和数量，密钥动作/输入/确认合并计数，不显示新旧值；范围以该表单成功加载目标为准，详见 [AI未保存字段摘要](ai-draft-fields.md)。

连接设置顶部现提供[未保存字段摘要](connection-draft-fields.md)，分别核对实际加载连接、主人和新增表单的改动字段名称与数量；不显示字段值，保存与重启仍按原规则执行。

日志页可[清空当前显示](log-clear-display.md)：仅移除本页已显示记录，保留读取位置、筛选和更新状态，统计与导出仍使用服务保留记录；需要再次查看近期日志时重新加载后读取。
