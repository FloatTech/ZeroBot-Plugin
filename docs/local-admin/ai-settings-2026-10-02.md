# AI 设置与基础缺陷修复

## 实现范围

后台新增“AI 设置”，管理聊天、识图与 Agent 的接口类型、地址、模型和独立密钥，以及提示词、最大输出长度、TopP、分隔符与推理努力度。指定正整数群号后，分别管理聊天群参数和 GPT/群总结温度。没有另建一份网页配置：与原聊天配置指令共用 `data/control/plugins.db` 的扩展数据和群参数。

保存成功后，后续消息读取新配置，不需要重启；已经开始的请求继续使用其配置快照。全局配置变化会清理 Agent 实例，后续创建新实例。配置修改不会替用户切换插件启停或响应/沉默，也不会自动调用真实模型。

| 设置 | 校验与含义 |
| --- | --- |
| 接口类型 | OpenAI、OLLaMA、GenAI；识图和 Agent 使用各自类型与密钥 |
| 接口地址 | 完整 HTTP/HTTPS 请求地址；新地址不允许用户名、密码、查询参数或片段；端口 1～65535；认证放在独立密钥字段 |
| 聊天模型名 | 非空；识图、Agent 模型名和地址可留空，保留原回退规则 |
| 密钥 | 默认保留；替换需输入新值；清除需明确选择并确认；普通读接口只返回是否已配置 |
| 最大输出长度 | 0～131072；0 使用默认 4096，实际支持范围仍取决于模型 |
| TopP | 0～1；0 使用默认 0.9 |
| 系统提示词、Agent 性格 | 最长 32768 个 UTF-8 字节；其他普通文本最长 256 字节 |
| 聊天非 @ 触发概率 | 0～100 百分比；与响应 @ 开关分别设置 |
| 群温度 | 0～100 百分比；0 保留原默认值 70，实际 0.7；聊天与 GPT/群总结分别保存 |
| 其他聊天群参数 | Agent 模式、QQ AI 语音输出、响应 @；保存时保留其他位、默认标志和插件开关 |

首次没有持久化 AI 配置时展示原默认配置；无密钥的部分设置不会被初始化逻辑清除。OLLaMA 可使用无密钥接口；OpenAI/GenAI 聊天需要配置独立密钥。

## 持久化与凭据

网页和聊天入口通过同一 Manager 锁执行读取、合并、备份和提交；群参数使用事务保留继承标记。提交成功后才更新缓存或清理 Agent；备份/SQL 失败保留原设置。网页旧版本提交返回冲突，不覆盖聊天或其他网页的新修改。全局版本使用进程内随机密钥的 HMAC，重启后旧页面需重新加载。

实际修改前备份整个控制库至 `.local/admin/backups/*-control/`，包括当时的 AI 密钥，沿用本机私有权限；普通读接口与静态网页不公开这些备份。没有修改则不重复备份。该钩子也覆盖共用扩展写入口；群参数备份仅安装在 `aichatcfg` 和 `llm`，避免业务计数每次变化都产生备份。沉默、黑名单等其他写入以及完整恢复页面仍待后续阶段。

未修改字段和未知扩展字段原样保留。含认证信息的旧 URL 只展示隐藏后的地址，不编辑就保留原值。配置展示隐藏已知密钥；模型请求失败不回显提供商响应正文、请求头或密钥。新设置不允许在 URL 中放认证，旧地址不会被自动改写。

## GPT 与总结修复

- `/gpt 问题` 只在文本开头匹配，并要求命令后有空白边界；支持首尾空白及回复消息。普通句子提及 `/gpt`、`/gptabc`、`/gpt问题` 不触发该处理器；空命令给出用法。
- 被回复消息的文字与当前问题以换行拼接。长回复按最多 1000 个 Unicode 字符分段，保留全部换行，中文及 emoji 不截断 UTF-8。
- GPT 和群总结共享每个群/每个私聊 30 秒一次的请求额度；不同群、不同私聊分别计算。失败尝试也占用本次窗口；并发请求受锁保护，额度表有容量上限。原有同时请求保护保留。
- 协议构造失败返回非 nil 错误；模型 HTTP 请求最长 30 秒，网络或提供商错误返回不含凭据的提示。

页面说明了模型接收的数据：聊天消息、上下文和系统提示词；回复消息附带被回复文字；群总结附带所选近期消息的昵称和文字，最多 1000 条。

## 验证与限制

自动化覆盖保存/读取一致性、未知字段保留、数据库重新打开后持久化、群隔离、密钥保留/替换/确认清除、URL 脱敏、非法输入、并发冲突、备份/SQL 故障与事务回滚。GPT 单元测试覆盖三种协议构造、非 nil 错误、超时、提供商错误脱敏、Unicode 分段与限速边界。

完整 Windows 程序使用独立临时数据库、合成 QQ 事件和本地模拟 OpenAI 服务；只使用假密钥，不发送真实 QQ 消息或付费模型请求。真实模型兼容性、AI 页人工交互及 Agent 操作/识图/语音的全部业务组合尚未验收；不能据此宣布整个 P0 完成。

原认证、插件注册表、网页/聊天开关、连接保存与备份、27 个群响应场景、5 个全局场景、帮助文字及服务列表图片同时通过。测试开始前仅在临时控制库禁用词典闲聊和概率回复，避免外部闲聊的随机延迟干扰命令断言；日常插件配置不受影响。
