# 日志快捷时间范围

在本机后台登录后，进入“运行日志”，点击“最近15分钟”“最近1小时”或“最近24小时”。按钮立即应用以点击时刻为结束、向前回溯指定时长的固定范围，精确到秒。开始和结束时间会回填表单，已应用条件列出实际本地时间。

快捷按钮沿用最近已应用的级别和关键词；尚未点击“应用”的输入不会一并提交，表单会恢复为实际应用值。“不限时间”只移除起止时间，保留已应用的级别和关键词；“清除筛选”则移除全部条件。

查看、匹配统计和下载日志使用同一起止时间。范围不会随轮询、重新加载、切页或下载自动向前移动；要查看更新的时间段，再次点击快捷按钮。暂停更新时只更换条件并清空旧结果，恢复更新后读取；仍可下载该范围的日志。切换条件会取消旧读取和下载，迟到结果不能覆盖新条件或重新登录的会话。

使用浏览器本地时区与本机时钟；24小时表示实际经过的24小时。若系统时间无效，或夏令时回拨使起止时间无法由本地输入框准确表示，拒绝快捷应用并保留原条件和结果，页面提示手动选择可明确表示的时间。退出或会话过期清空筛选。

此功能仅筛选本次启动仍保留的脱敏日志，不读取磁盘历史，不增加原有1000条保留量，不生成日志、修改配置或调用QQ/模型。选择24小时不保证存在24小时的历史记录。

验收：先应用级别/关键词，点击不同快捷范围，核对回填值与已应用提示；暂停后换范围并下载，恢复更新后核对统计。“不限时间”应保留级别与关键词。实际页面体验待验收。

自动化验证：新增4项离线Chrome测试通过；完整界面137项中132项在沙箱通过，5项旧下载用例因沙箱取消下载失败，对应两个测试文件9项在正常Windows权限下重跑全部通过。64项页面布局及深浅窄屏截图通过；相关Go模块与静态检查、Windows构建通过。首轮Go测试受沙箱ACL/回环网络限制，在正常权限下重跑通过。真实页面体验另待用户验收。

暂停日志更新时可点击“读取一次”，按已应用条件读取新日志和匹配统计，完成后仍保持暂停，见 [暂停时读取一次日志](log-read-once.md)。
