# 放弃单个插件的未保存更改

登录本机后台进入“插件列表”。编辑某个插件开关后，其卡片底部的“放弃此项更改”可用；点击后核对确认框中的插件名称与已读取的全局/群范围，再确认放弃。

确认后，只恢复该插件最近一次成功读取或保存的开关选择，清除该项“未保存”标记。其他插件的草稿（包括其他页和筛选隐藏项）、已保存的开关、实际状态和版本保持不变；不会发请求、写配置或创建备份。取消确认则保留原编辑。

搜索、状态筛选、只看未保存、排序和每页个数保持。放弃后会重新筛选、排序及校正页码：只看未保存时该卡片消失，未保存优先排序时卡片可能移动，最后一页变空时回到有效页。用法窗口仍对应打开时的插件。

无草稿时按钮禁用；当前插件没有可编辑状态时不显示此操作。读取/刷新、单项保存或逐项保存全部草稿期间不可放弃。确认期间若发生目标、范围、基线、草稿或登录会话变化，旧确认不再执行，需重新核对。退出或会话过期仍按原规则清空全部草稿。

放弃恢复的是页面最近成功读取的值，不会重新查询机器人。如果保存曾提示版本冲突，放弃后仍需“刷新插件状态”核对最新值。已经保存成功的开关不能用此按钮撤销；需要重新选择并保存。界面只保留内存中的草稿，不写浏览器存储。

验收：编辑两个插件但不保存，对其中一项先取消、再确认放弃，核对另一项草稿和实际启用状态保留；组合只看未保存与未保存优先排序，检查卡片位置、计数及分页。无需保存日常开关。实际页面体验待验收。
