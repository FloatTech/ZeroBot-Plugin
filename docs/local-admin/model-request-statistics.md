# 模型接口请求统计

后续DEV-74已补齐[观察起点与报告下载](model-observation-report.md)，可保存同一启动起点的前后累计快照与请求次数变化。以下DEV-73记录保留原构建/时间；当前窗口报告不计算窗口最长耗时、不等同QQ端到端延迟或业务验收。

登录本机后台，在“运行概览”查看“模型接口请求”。页面沿用概览的10秒自动更新与“刷新状态”按钮；离开页面或隐藏标签暂停读取，重新进入重新读取。未登录不能读取统计；退出、切页、隐藏或读取失败会清除旧显示，避免把旧统计当成当前值。

统计在运行新版机器人后开始，无需修改AI配置或发送测试消息。数据只在本次ZeroBot进程内累计，重启后重新开始，页面显示统计起点。NapCat重启、概览刷新或AI配置热更新不会主动清零；旧程序运行期间的数据不能补记。没有已结束请求时显示“耗时待统计”，不是耗时为零或业务已通过。

四个固定类别：GPT／群总结、普通聊天、Agent、识图。Agent每轮实际接口请求单独计数，识图用单独配置的图片模型接口计数，Agent回退聊天会进入聊天类别。同一用户消息可能触发多次接口请求。不会统计QQ内置语音、图片下载、非模型插件、没有发出请求的参数校验/限流拒绝，或其他工具直接调用的接口。

## 统计口径

| 显示 | 含义 |
| --- | --- |
| 发起 | 已进入上述模型客户端的HTTP传输次数；重定向每一跳单独计数，不等于QQ消息数或模型任务数 |
| 进行中 | 尚未结束传输，包括已收到响应头但仍读取响应的请求 |
| 接口完成 | 2xx响应，读到结束或读完声明的响应长度；不证明解析成功、内容有效、Agent动作获准或QQ发送成功 |
| 失败 | 网络/取消/超时/响应读取错误、非2xx响应；重定向3xx跳也在此类，后续跳可能完成 |
| 提前关闭 | 2xx响应未核对完整就被调用方关闭；可能是解析错误或只读取部分内容，并不自动等同业务失败 |
| 平均与最长耗时 | 所有已结束传输（包括失败与提前关闭）从进入HTTP传输到读取完成、报错或关闭的时间；页面以秒显示，接口以毫秒返回；不包括前置提示组装、排队或QQ发送时间 |

响应正常传输和“用户收到正确回复”属于不同证据。未知长度响应必须读到结束；解析器若提前结束而没有再读取结束标记，将显示提前关闭。客户端的超时、重定向策略、Cookie处理和原传输保持，不增加请求、重试或主动读取剩余正文。

统计只保存固定类别、次数、时间与耗时汇总，不保存逐条请求历史、QQ/群号、模型名称、接口地址、消息、图片、密钥或原始错误。不会写入配置或备份，不提供清零/修改接口。内存容量不随用户/请求历史增加；响应期间仅保留一次结束回调，结束重复通知不重复计数。

维护工具可使用已登录的同源只读`GET /api/overview`中`modelRequests`对象取得累计快照。它沿用本机地址、来源和后台会话限制，响应禁止缓存；没有统计来源返回`null`，不能当作0。对比两个快照须核对统计起点一致，否则跨重启的差值无效。`observe-live-services.ps1`仍只采资源和日志，尚不读取这个接口，不能直接宣称同时取得请求数量或端到端回复延迟。
