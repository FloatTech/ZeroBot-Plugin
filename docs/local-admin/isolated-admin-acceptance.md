# 本机隔离后台验收环境

用于 TODO-BACKUP-01 / TODO-UI-01 的真实页面操作。按用户2026-10-12的选择，由自动浏览器执行这些流程，无须逐页人工查看。它复制当前程序到新的忽略目录，创建独立配置、控制数据库、后台密码和模拟 OneBot；不读取日常启动配置、控制库、凭据或 NapCat 登录，不向真实 QQ 或模型发送测试请求。页面会显示合成账号和数据，不能据此判断日常机器人在线。

从真实仓库目录执行：

```powershell
Set-Location <项目目录>
$env:CGO_ENABLED = '0'
go run scripts/start-admin-acceptance.go -binary-name zerobot.exe
```

需要 Go、可读取的 `.local/bin` 程序/固定启动素材，以及启动临时进程和本机回环监听的权限。终端保持打开，工具就绪后输出本次 URL、登录说明文件和产物目录。默认最多运行 30 分钟，可用 `-lifetime 10m` 调整（1～120 分钟）。后台为随机回环端口，密码每次随机生成，保存在该产物目录的 `login.txt`，不使用日常后台密码。

仅在自己的浏览器打开本次 URL；自动浏览器的本机访问权限限制仍按原约定保留，本工具不改变权限。登录后使用页面显示的三个基线备份编号，分别预览和恢复启动配置、控制库、后台选项。当前测试值已与基线不同，可核对差异、确认、写前备份、重启提示和恢复后数值。合成主人为 `12345678`，测试群为 `101`，参数基线为 `isolated-baseline-model`，临时值为 `isolated-edited-model`。这些不是实际 QQ 目标。

在启动器终端输入 `restart`，只重启本次测试程序并更新 `session.json` 中的 URL；浏览器重新登录，再核对恢复后的主人/插件/模型与重启提示。`status` 输出当前测试入口，`stop` 或 Ctrl+C 结束并停止测试程序。终端输入结束或运行期限届满也会停止。资料和日志保留在 `.local/admin-acceptance/run-*`，不会自动删除，且不进入 Git。

如在测试页修改后台密码，后续重新登录使用你设定的新测试密码；`login.txt` 保留初始值，不自动更新。终端重启不代替浏览器登录，不会因初始密码已变更而拒绝启动。

## 完整恢复页面验收步骤（支持自动浏览器执行）

使用本次`session.json`中的URL和`login.txt`中的随机测试密码登录自己的浏览器，进入“备份恢复”。不要打开日常后台3010进行此演练。记录本次三个基线编号；同范围还有自动写前备份，按编号选基线，不能仅选最新一条。

1. 手动创建一份“控制数据库”备份，确认列表出现新编号，再预览并取消。取消后AI模型名仍为`isolated-edited-model`，群101的chrev仍启用。
2. 预览本次控制数据库基线，核对范围/编号/影响摘要。先不勾覆盖确认，恢复按钮应不可用；勾选后恢复。成功后AI模型名为`isolated-baseline-model`；进入插件页等待自动读取，核对群101的chrev停用；DEV-64已修复首次空列表，读取失败才需刷新重试；备份列表应保留恢复前状态的备份。
3. 预览并确认恢复启动配置基线。“连接设置”主人应从两个合成账号恢复为仅`12345678`，页面提示需要重启。模拟OneBot的连接地址和Token保持，不改为真实连接。
4. 预览并确认恢复后台选项基线，应成功并提示重启后生效。本次当前端口继续可用；恢复后的地址是准备时的原测试端口，重启后URL可能改变。
5. 自动浏览器读取前三类恢复成功状态；调试者仅重启本次测试实例，并获取更新的URL。自动重新登录后核对主人、AI模型和chrev仍为基线，且原随机测试密码保持。测试完成后停止此实例。

某一步失败时记录该范围、实际提示和是否改变了页面值，不继续其他范围来掩盖失败。真实页面操作、重启后只读核对和用户反馈分别记录；用户反馈不是本流程通过的前置条件；环境就绪、自动检查通过或单次恢复成功都不代表整个页面矩阵验收通过。

重启前只接受本次模拟 OneBot 的原连接和 Token，以及本次准备的后台端口；连接被改为其他地址、增加真实连接或后台被禁用时拒绝重启，当前实例保留，先恢复基线再试。该限制用于保持验收范围，不是产品连接校验规则。关闭终端之外强制结束父进程可能跳过清理，应优先使用 `stop`；不要用日常服务停止脚本停止测试实例。

自动检查环境准备和恢复重启链路时可执行：

```powershell

```

自动检查使用同样的新目录，确认样本差异、三类恢复、重启、旧会话拒绝、随机密码保持及地址守卫后退出，不留下运行实例。`result.json` 会明确标记自动环境检查和人工验收的区别；启动就绪、自动检查通过或正常停止都不会自动关闭真实页面待办，也不计作真实 QQ / 模型 / 长期性能验收。

测试环境只准备本机合成配置与固定素材，不是完整数据副本。不要在测试页填入真实 Token、模型密钥、群号或公网接入地址。标准程序原有素材/公告初始化仍可能访问其既有外部资源；工具不提供通用网络隔离或完整插件素材。更多恢复限制见[备份恢复](backup-restore-2026-10-02.md)。
