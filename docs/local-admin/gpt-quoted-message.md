# GPT 引用原文与本次要求

私聊，或已启用`llm`且响应有效的群中，使用QQ的消息引用/回复功能选择有文字的消息，再输入`/gpt 本次要求`。确认输入框出现引用卡片，仅@发送者不代表有引用消息段。需满足原群响应、插件与角色规则；GPT与群总结在同一群或同一私聊仍共用30秒一次额度，正在处理的同会话并发请求仍可能被忽略。

同时存在引用文字和新要求时，提交模型的提示会明确列出“引用原文”和“本次用户要求”，原文编码为JSON字符串以保留换行、引号、反斜线和中文/emoji，且明确新要求不属于原文。没有引用的普通`/gpt 问题`保持原输入；只有引用文字、发送`/gpt`而没有新要求时，仍按原方式提交引用文字；两者都没有则提示用法。

例如引用“私聊调试成功”后发送`/gpt 请原样重复引用文字`，期望只回复被引用文字，不把新要求一起复述。其他要求如“解释这段代码”“给这段文字起标题”仍交给模型处理，不根据测试用语直接回显固定答案，不绕过模型调用。提示边界改善输入含义，不能保证所有模型都严格遵循输出格式。

模型接收引用文字和本次要求；只读取当前指令引用的消息，不扩大为额外聊天历史。不改变密钥、模型、系统提示词、人物设定、群/私聊参数、温度、限速或回复长短的发送方式。程序升级并重启ZeroBot后供后续请求使用，已开始的请求不被改写。识图、语音以及其他权限角色另验收。
