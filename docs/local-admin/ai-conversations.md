# AI 群聊与私聊参数

登录本机后台进入“AI 设置”，在会话范围中选择“指定群”或“指定私聊”，填写对应群号或与机器人聊天的用户 QQ，点击“查看会话参数”。私聊填写用户账号，不是机器人账号。输入编号必须是正整数，不能填写内部负号。

聊天参数可分别修改触发概率、温度、Agent、语音和响应 @；GPT 的温度单独保存。后台和聊天配置指令共用同一会话数据：群号与相同数字的私聊 QQ 属于两个不同会话，互不覆盖。保存前备份，成功后供后续消息使用，无需重启；不会修改其他会话、模型密钥或人物设定。

切换会话前会提示未保存更改，取消则保留编辑；读取失败保留原表单和已加载范围。每个表单标题标明当前实际群号或私聊 QQ。下拉框和输入框用于选择下一次读取的范围，仅改变它们不会改变已加载表单的保存目标。

私聊设置不会放宽 Agent 动作权限，也不会自动开启插件或会话响应，不会发送测试消息。`/gpt` 始终使用聊天接口，私聊不存在群总结；部分开关只在原聊天逻辑适用时产生效果。普通成员能执行的 Agent 动作仍受原权限表约束。
