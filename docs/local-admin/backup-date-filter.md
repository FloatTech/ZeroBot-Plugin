# 备份日期筛选

登录本机后台，进入“备份恢复”，在列表上方填写“开始日期（本地）”和“结束日期（本地）”，点击“应用日期”。可只填写一端；两端都留空表示不限日期。结束日期包含当天完整一天，按浏览器本地时区计算，不是UTC日期，也不是最近24小时。

日期输入尚未应用时，列表、分页、内容大小摘要和下载清单继续使用原已应用条件，并显示提示。无效日期或开始晚于结束不会替换原条件。应用后回到第一页，与原关键词、范围、校验状态组合筛选，保留排序和每页份数。“清除筛选”同时清除日期、关键词、范围与校验状态，保留排序。

只筛选本次已加载的最新200份备份；更早未加载的记录不会因日期选择而被补充读取。有日期限制时，只纳入有效备份中可核对创建时间的记录；损坏或无法核对时间的备份不按编号猜测日期。不限日期时仍按原规则展示这些记录。筛选不代表可以恢复，恢复前仍需预览和服务端校验。

筛选在浏览器本地完成，不新增接口，不创建、恢复或删除备份。日期筛选不会改变已选恢复目标、清理预览或确认；清理仍按原保留策略检查整个受控备份目录，不按列表筛选删除。分页和大小摘要基于全部已加载匹配项，下载清单沿用已应用日期，并在filters中附fromDate、untilDate和dateTimeZone（日期不限时不增加这些字段）。清单仍仅供核对，不能恢复配置。

请求处理期间日期控件禁用；刷新、切换后台页面保留日期输入和已应用条件，刷新失败保留旧结果并标记。退出或会话过期清空日期，旧请求不能覆盖新会话。条件只存在当前页面内存，不写浏览器存储，刷新整个网页后重置。

验收：选择已知备份日期，核对起止当天边界、单端筛选、条件组合及清除；确认大小摘要和清单只包含全部匹配项，原恢复/清理目标保持。自动化使用合成元数据，无需恢复日常配置、清理日常备份或发送真实QQ消息。实际页面体验待验收。
