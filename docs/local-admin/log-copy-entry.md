# 复制本条日志

登录本机后台，进入“运行日志”，在需要的记录下点击“复制本条”。复制文本为页面显示的本地时间、级别与日志正文，保留换行、Unicode文字及已有脱敏/截断标记。来源是该条已显示内容，不额外请求原始日志；页面未显示的字段、原始消息正文、配置、认证信息不会被附加到复制文本。

成功后该条显示“已复制本条日志”。同一条正在复制时禁止重复点击；不同记录分别显示结果。运行中或暂停时都可复制，不改变筛选、增量游标、匹配统计、暂停、自动滚动或导出条件，不生成备份，不修改机器人配置，不发送QQ消息或调用模型。

浏览器禁止或不支持剪贴板写入时，页面选中该条日志正文并提示按Ctrl+C手动复制；手动回退只选正文，时间与级别可另行选取。复制失败可重试。提示成功仅表示浏览器确认系统剪贴板写入完成。

未登录、未进入日志页或页面隐藏时不能复制。切换筛选、重新加载、暂停/恢复、切页、隐藏页面、退出或会话过期清除旧复制提示，使未完成操作的界面结果失效；断档重置或容量淘汰后，已离开当前列表的记录也不会再显示迟到结果或选中文字。已交给浏览器的剪贴板写入无法撤回；页面失效后不会再显示成功或执行手动选择。

页面仍只保留本次启动最近最多1000条，服务器容量上限与脱敏规则保持。复制的是最近成功读取后已显示的内容，不保证与此刻服务端保留范围完全一致。需要全部仍保留的筛选日志时使用原“导出筛选日志”。

验收：读取日志后复制一条，核对时间、级别、换行、脱敏和暂停状态；剪贴板拒绝与迟到结果由隔离测试覆盖，无需发送真实QQ消息。实际页面体验待验收。
