# 新增正向 OneBot 连接

登录本机后台，进入“连接设置”，先读取启动配置。在“新增 OneBot 连接”中选择“正向连接”，输入接入程序提供的 ws:// 或 wss:// 地址，并输入对应 Token。接入程序确实不使用 Token 时，勾选“我确认此连接不使用 Token”；该选择会清空新 Token 输入。点击“备份并新增连接”，确认后保存。新增会附加到正向连接列表，自动选中新增项，显示旧配置备份与待重启提示。

保存只修改当前实例的启动 JSON，不立即连接或重启，不改变 NapCat 的监听与账号；需要接入程序已配置相同地址/Token，下次重启 ZeroBot 后加载。此说明描述正向新增；选择“本机反向监听”时要求本机地址与 Token，见 [本机反向监听](reverse-connection.md)。另行删除已有连接见 [删除连接](connection-delete.md)。最多允许保存64条正向连接；已有超过上限的配置仍可通过原编辑功能管理。

地址必须符合原 ws/wss 校验，认证信息须填在 Token 中，不能放到地址的账号、查询参数或片段中。同一正向列表中的等价地址拒绝重复（主机大小写、默认端口、空路径与根路径视为相同）；不尝试网络连通性。Token最长2048字节，不能是控制字符或脱敏占位。新增项不复用任何旧 Token。

新增与现有连接/主人编辑分别保存；现有连接或主人有未保存草稿时，先保存或放弃它们再新增。新增草稿切页保留；选择已有连接或单独撤销旧草稿不清空新增输入。重新加载配置或退出先确认，取消/读取失败/写入失败/冲突保留新增草稿；成功重新读取、放弃新增或退出/会话过期清空。新增请求中冻结操作，迟到结果不能回填新会话。新增 Token 只留在当前页面内存，不写浏览器存储，不通过普通接口或错误提示回显。

保存采用原版本校验、受限写前备份与原子替换，保持其他正向/反向连接、主人、未知字段与大整数。冲突时原配置保留，请确认草稿后重新读取；备份失败不能继续保存。临时测试覆盖新增后的重新读取/启动快照以及写入失败，不用日常连接做测试样本。

验收：检查新增表单、填写模拟地址后切页返回/放弃，核对未保存提示和原连接保持；实际新增请使用自己的已配置接入程序，保存后按需要重启，不以日常配置做破坏性演练。完整QQ业务待办保持原范围。

自动化验证：新增4项Go覆盖旧字段/大整数/运行快照、备份与重新加载、地址/Token/上限/互斥校验、无连接与大小写字段、备份/写入失败、并发冲突及API认证/秘密隐藏；新增4项Chrome与原86项共90项界面，64项布局及桌面浅色/窄屏深色截图通过。02:10:56完整Windows隔离回归中新增/重复/旧版本、备份恢复与原有指令全部通过，未发送真实QQ消息或调用模型。网络失败未确认成功时先读取核对，避免重复尝试；不以隔离测试代替真实自有接入程序验收。

本机部署：原启动配置、控制库、日常后台凭据保持，NapCat进程/登录保留、ZeroBot身份单实例正常，新脚本与原认证、正确账号/OneBot握手通过，无新增启动错误。证据见 [自测记录](self-test.md)。升级仅重启ZeroBot，后台可使用原密码重新登录。

连接设置顶部现提供[未保存字段摘要](connection-draft-fields.md)，分别核对实际加载连接、主人和新增表单的改动字段名称与数量；不显示字段值，保存与重启仍按原规则执行。
