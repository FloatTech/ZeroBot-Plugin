# 下载备份清单

登录本机后台，进入“备份恢复”，读取列表后按编号、日期、范围或校验状态筛选，点击“下载筛选清单”。生成 UTF-8 JSON 文件，收录所有已加载且符合当前筛选的记录，跨页保留；每页份数和当前页码不限制下载。零匹配也可下载空清单用于核对。生成后立即生效，不需重启机器人。

清单包含备份编号、创建时间、范围、内容字节数、格式版本、是否含校验摘要及本次读取的可预览状态；附清单格式版本、下载时间、最近成功读取时间、加载和匹配数量、是否另有未加载记录、是否刷新失败。范围/状态筛选和是否使用关键词会记录，关键词原文不会写入文件。仅加载最新200份时明确标记有更早记录未列入。

文件名以 zerobot-backup-catalog- 开头，可用文本编辑器打开。时间以UTC（末尾Z）保存，页面时间则按本机时区显示。scope字段中 startup-config 是启动配置，control-db 是控制数据库，admin-options 是后台启用与地址；unknown 表示无法确认的范围。source.loaded/matched 是已加载/匹配数量，more 为 true 表示还有更早未加载备份，lastReadFailed 为 true 表示最近列表刷新失败。无效编号、时间或数值使用 null，不猜测有效内容。

这是当前页面缓存的目录快照。刷新失败后仍可下载上次结果，文件和提示标明失败；已加载记录不保证本机文件仍存在或可恢复，恢复时仍须原预览/校验/确认流程。清单不包含配置正文、密钥、数据库、聊天记录、恢复凭证或实际校验摘要，不是可用于恢复的备份文件，不提供清单导入。未知范围和无效元数据使用固定占位，不输出额外字段。

加载、创建、恢复或清理进行中以及未登录、尚未加载列表时不能下载；切离本页禁止下载，退出或过期清除缓存与提示，旧请求不能回填到新会话。返回本页按原流程重新读取。下载在浏览器本地完成，不新增接口请求，不创建/删除备份，不修改机器人配置。文件按浏览器的下载设置保存；提示“已发起”不保证用户已保存文件。下载失败可检查浏览器设置后重试。

验收：筛选控制库并切到第2页，下载后用文本编辑器查看，记录应包括该筛选下所有页；核对编号/数量、最近读取时间及部分加载提示。清除筛选后再次下载应恢复全部已加载记录。不要通过清单执行恢复，真实恢复继续使用原页面。

清单记录 `filters.sort`，备份条目顺序与所选列表排序一致，见 [备份列表排序](backup-sort.md)。

备份列表可按本地开始/结束日期组合筛选，结束日期包含完整当天；列表、大小摘要与清单采用同一组已应用日期，清理策略和恢复目标保持，见 [备份日期筛选](backup-date-filter.md)。
