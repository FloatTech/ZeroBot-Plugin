# 连接设置编辑保护

登录本机后台进入“连接设置”。编辑 WebSocket 地址、Token 操作或主人 QQ 后，页面提示未保存；恢复读取时的值会清除提示。草稿只保留在当前页面内存中，切换后台页面仍保留，不写浏览器存储。

选择另一个连接时，如果当前连接的地址或 Token 有未保存修改，先确认是否丢弃；取消恢复原连接，继续则读取已加载的另一连接值。主人账号属于整个启动配置，切换连接不会丢弃主人草稿。保存目标始终是表单实际加载的连接。

“重新加载配置”和退出登录会对所有未保存修改提示确认；取消不发请求。确认重新加载后，成功才替换表单，读取失败保留原值、选择和版本。保存失败或配置冲突保留草稿；成功后清除已保存草稿和新 Token 输入，显示“待重启生效”（如果保存值与启动值不同）。不会自动重启或修改 NapCat。

保存/读取中禁用表单和重复请求，退出提示等待。关闭或刷新浏览器时，有草稿或请求未结束会请求原生离开提醒；实际是否显示取决于浏览器及用户交互状态。退出成功或会话过期清空地址、主人、Token 和草稿，迟到的旧会话读写结果不会回填、解锁或覆盖新页面。

当前 Token 不通过读接口返回，替换值只输入在密码框，提示只描述字段类型，不显示敏感内容。保留、替换、显式清除及清除确认保持原语义，备份包含凭据且仅存本机。后台登录权限、写前备份与其他连接/未知字段保留规则保持不变。

验收：仅修改表单，核对未保存提示；取消重新加载、退出及切换连接，确认输入保留；切换后台页面再回来确认草稿保留；改回原值确认提示取消。保存会影响下一次启动连接，实际日常地址无需故意改错。多连接、失败/冲突、过期与迟到响应由隔离测试覆盖。
