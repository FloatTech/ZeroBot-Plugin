# 待保存插件开关

登录本机后台进入“插件列表”，在未保存提示下勾选“只看未保存”，集中查看当前全局或指定群范围的开关草稿。仍按搜索名称/功能/用法与实际状态筛选，再分页；条件变化回到第一页。“清除筛选”同时取消只看未保存，草稿仍保留。筛选不会发请求或保存开关，实际启用/禁用统计不把草稿视作已生效。

顶部未保存数量包含所有页及当前条件隐藏的草稿，可继续单项保存，也可使用 [逐项保存全部插件草稿](plugin-save-all.md)，确认后包含隐藏项逐个保存；遇错或手动停止时保留余下草稿。保存成功只清对应草稿并重新筛选；保存失败保留选择与版本。将开关改回读取时的值会取消该草稿，在只看未保存时该卡片消失；结果减少后页码自动校正。没有草稿与有草稿但条件无匹配分别提示。

“放弃全部更改”撤销当前范围内所有未保存开关选择，包括隐藏的草稿。点击后先确认数量，取消则原样保留；确认后恢复已读取的选择，不发送接口、不修改已保存的实际规则，也不创建备份。没有草稿或请求中按钮禁用。若此前出现版本冲突，放弃只恢复最近读取的页面状态，需要“刷新插件状态”重新读取最新规则。已经保存成功的开关无法通过此按钮撤销；若需要修改已生效规则，请重新选择并保存。

读取、刷新或保存期间禁用这两个新入口；原刷新/换群/退出的草稿确认不变。只看未保存跨后台页面保留，退出/会话过期或浏览器重载后取消，旧请求不能改变新会话；草稿只保留在页面内存。此功能不改变全局/群优先级、权限、QQ登录、模型设定或对话记录。

验收：任选两项修改但不保存，勾选只看未保存核对数量与卡片；改变搜索确认草稿不丢失；改回一项原值确认该卡片消失；点击放弃全部更改先取消再确认，核对已生效标记保持。无需保存日常开关，成功保存、冲突、忙时与会话场景用隔离测试覆盖。
