# 暂停时读取一次日志

登录本机后台，进入“运行日志”，先点击“暂停更新”，再点击“读取一次”。页面按已应用的级别、关键词与起止时间读取一次新日志，并更新匹配统计；完成后继续保持暂停，不启动自动轮询。

未点击“应用筛选”的输入不会随读取提交。已有记录按原游标增量追加，重复记录不重复展示；新应用条件或“重新加载日志”清空结果后，读取一次使用最新页，最多返回200条匹配记录。服务器仍只保留本次启动最多1000条/总容量1MiB，页面仍最多显示1000条。一次读取不保证补齐暂停期间的全部记录；有淘汰、断档或实例变化时沿用原提示与重置规则。

匹配统计仍表示服务端保留快照中全部符合条件的记录，不等于此次返回条数；没有新增记录也可以更新统计。自动滚动沿用当前勾选状态，固定的快捷时间范围不会自动移动。导出继续使用同一组已应用筛选条件，范围为服务端仍保留的全部匹配记录。

自动更新开启时“读取一次”禁用；请求中禁止重复点击。读取失败保留已有记录和最近成功统计，保持暂停，不自动重试，可再次点击读取。读取期间点击“恢复更新”会取消旧请求并按原流程启动自动更新。

切换筛选、切页、隐藏页面、退出或会话过期取消旧读取；迟到结果不能覆盖新条件或重新登录的会话。切换页面保留原暂停选择，返回后可再读取一次。此操作只调用原认证、脱敏日志读接口，不写配置、不生成日志、不调用QQ或模型。

验收：暂停后点击读取一次，核对新增日志/统计与暂停状态；重复点击、输入未应用、无新增记录、读取失败后重试等由隔离测试覆盖。无需发送真实QQ消息或调用模型。实际页面体验待验收。

## 自动化验证与部署

运行日志每条记录可点击“复制本条”，只复制页面已显示的时间、级别与脱敏正文，剪贴板受限时选中正文手动复制，详见 [复制本条日志](log-copy-entry.md)。

日志页可[清空当前显示](log-clear-display.md)：仅移除本页已显示记录，保留读取位置、筛选和更新状态，统计与导出仍使用服务保留记录；需要再次查看近期日志时重新加载后读取。
