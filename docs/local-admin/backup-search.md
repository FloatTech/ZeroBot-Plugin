# 备份列表检索与筛选

登录本机后台进入“备份恢复”。列表上方可输入备份编号、范围名称或日期，并组合“备份范围”和“校验状态”筛选。日期支持列表显示的本地日期文字或元数据 ISO 日期；关键词不读取备份文件内容，也不搜索凭据。

范围包括启动配置、控制数据库、后台启用与地址，以及异常/未知范围。校验状态区分可预览且含摘要、可预览但无摘要的旧版，以及不可恢复。含摘要不代表该备份适合当前业务；恢复仍需后端重新校验和明确确认。不可恢复的卡片不能预览。

筛选即时调整本次已加载列表，不发送写请求、不创建或删除备份。“清除筛选”恢复所有已加载记录。计数显示匹配数/加载总数及状态分布；没有备份和没有匹配结果分别提示。后台每次最多返回最新 200 份，存在更早未加载记录时明确提醒：搜索只覆盖本次加载范围。

搜索、范围与状态条件在切换后台页面、刷新列表及创建/恢复后的刷新中保留；退出或会话过期清空条件和缓存。读取失败保留上次已加载结果并标记读取失败，不能把旧结果称为最新状态；再次成功读取更新列表并重新应用条件。请求中暂时禁用筛选和列表操作，旧请求结果不会覆盖新会话。

筛选不改变已打开的恢复预览或清理清单。恢复预览明确显示备份编号，即使该卡片被筛选隐藏，仍能核对预览的实际目标。恢复和永久清理保持原独立确认、版本/清单冲突、备份与回滚保护；本功能不自动执行这些操作。保存日常配置、后台密码、QQ 登录和 AI 人物设定不受筛选影响。

验收：组合范围、校验状态与编号/日期，核对计数；清除后恢复列表；打开预览后调整筛选，核对预览编号和确认目标；切页/刷新核对条件保留。无需恢复或删除日常备份来测试检索；损坏、旧版和隐藏目标由隔离测试覆盖。

自动验证：四项新增DOM用例覆盖范围/状态/编号/ISO日期/未知/空匹配、满载提示与文字安全、隐藏预览后的恢复ID、失败/刷新/跨页/创建条件保留、繁忙与会话重置；一项新增Chrome用例验证真实表单/导航、恢复编号和纯筛选无写请求。原47项加新增5项，共52项界面通过；56项深浅主题/320～1280px布局通过，核对桌面与窄屏截图（含预览编号）。Go模块/静态检查通过。

未恢复或清理日常备份，未修改日常开关/地址/Token/AI密钥/人物设定，未发送真实QQ消息或调用模型。已有素材MD5服务器网络警告仍存在，缓存素材可用。实际页面待 TODO-BACKUP-SEARCH-01；原备份恢复完整人工验收仍按其独立待办处理。

备份恢复页可按时间从旧到新、大小从大到小或从小到大排序全部已加载匹配项；分页和下载清单沿用所选顺序，见 [备份列表排序](backup-sort.md)。

备份恢复页提供已加载/匹配和固定范围的备份内容大小摘要，异常大小单列；不代表目录实际占用，见 [备份内容大小](backup-size-summary.md)。

备份列表可按本地开始/结束日期组合筛选，结束日期包含完整当天；列表、大小摘要与清单采用同一组已应用日期，清理策略和恢复目标保持，见 [备份日期筛选](backup-date-filter.md)。
