# 备份预览有效期提示

登录本机后台进入“备份恢复”，选择“预览恢复”，或在清理表单点击“预览清理清单”。预览下方显示截止时间和剩余分秒；时间仅按本机时钟估算，不表示当前配置或备份内容仍与预览一致。实际恢复/清理仍由服务端校验原票据、版本、范围和当前内容。

到期自动取消原确认、禁用确认框与执行按钮，并提示重新预览。恢复可在备份卡片再次点“预览恢复”；清理可再点“预览清理清单”。新预览必须重新核对并勾选确认，已判定到期的预览不会因为本机时间回拨而重新可用。缺少或无效的有效期也会阻止执行，不猜测可用期限。

仅当前已登录、可见的备份页面计时。页面隐藏时停止计时，返回可见时立即按当前时间重新核对；切页、取消、刷新或退出按原流程清掉对应预览和计时，迟到结果不能恢复旧会话。修改清理参数会取消旧清理预览。已提交的请求不会因页面倒计时到期而被中断或自动回滚，处理结果仍以原接口返回为准。

这只增强提示和本机确认保护，不自动续期，不发送计时网络请求，不自动恢复/删除，不更改备份保留策略或机器人配置；截止时间仍以服务端为准。无变化的恢复预览和空清理清单继续不能执行，取消仍可使用。秒级倒计时不连续向读屏软件播报，到期状态有单独提示。
