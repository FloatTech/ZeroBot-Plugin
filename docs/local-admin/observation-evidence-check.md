# 模型与资源观察证据核对

资源观察没有对应模型报告时，可仅运行`node scripts/check-observation-evidence.mjs --resource .local/live-observation/本次目录 --output .local/本次资源核对.json`。该模式只读取最终资源结果与原始样本，重新计算窗口、CPU/内存和阈值，沿用输入大小、秘密字段排除及独占输出保护；无需浏览器、后台密码或服务重启。不会读取日志正文、发送QQ消息或调用模型。

仅资源输出标记`mode=resource-only`，`resourceObservationPassed`表示资料有效、资源检查通过且采样时钟一致。退出0对应此标记；退出2表示资料有效但正式时长、节奏、阈值、身份、日志覆盖或时钟检查未通过；退出1表示无效文件/样本/摘要或输出失败。`compatible=false`、`sameProcessVerified=false`及`temporalCoverage=unavailable`保持，因为没有模型窗口可关联；`businessAcceptancePassed=false`不会因为资源观察通过而改变。附带`--model`时仍按下面原双来源口径核对与退出，不改变历史报告行为。

当前日常F86EA6构建15:31:38～15:46:38的180样本覆盖900.035秒，正式窗口/节奏/阈值/日志覆盖及原摘要独立重算通过；仅资源CLI退出0、`resourceObservationPassed=true`，关联与业务仍未证明。15:47:26只读核对ZeroBot PID110400/NapCat PID56644及原启动时间、五配置与QQ在线保持。14项界面资源摘要一致，本轮仅维护脚本和文档变化，无机器人构建、部署、重启或界面测试重跑。完整数值与原件见[日常资源记录](live-performance-observation.md)，证据`.local/live-current-resource-check.json`、`-daily-after.json`及`-final-evidence.json`。

维护者可在仓库运行下面的离线工具，核对已经保存的模型报告和资源观察目录。需要 Node.js 以及输入文件的读取权限；不需要后台密码、浏览器连接或管理员登录。工具不连接网络、不采样、不发送消息、不修改配置或控制服务，读取后立即生效，无需构建或重启机器人。

```powershell
node scripts/check-observation-evidence.mjs --resource .local/live-observation/本次目录 --model 本次模型报告.json --output .local/本次核对.json
```

请替换为实际路径。资源目录必须含最终 `result.json` 和原始 `samples.jsonl`；仅有进度文件不能使用。模型文件来自运行概览的[观察报告下载](model-observation-report.md)。输出文件必须尚不存在，工具不会覆盖输入或已有结果；省略 `--output` 时仅向终端输出结果。

工具重新计算资源摘要（含小数内存增长）、窗口长度、节奏和阈值，并与原结果核对；不会修正或改写原文件。模型报告支持版本1/2，核对四类累计次数、跨窗口进行中守恒、精确时间与窗口变化；版本2另核对[进程身份](model-observation-identity.md)。不从累计平均/最长值推算窗口耗时。不认识的附加属性不会复制进输出；聊天内容、QQ账号、配置、路径和错误正文不会写入核对报告，输出包含来源摘要、资源及版本2模型的PID/启动时间/程序摘要与固定检查说明。

结果区分以下内容：

- `evidenceValid`：文件结构、原始样本与已保存摘要、模型报告内部关系均有效。
- `resourceChecksPassed`：重新计算的正式窗口、资源阈值以及原结果的身份/程序/日志覆盖检查通过；日志计数不能从资源样本独立还原。
- `temporalCoverage`：模型窗口是否完整位于资源首末样本之间；部分重叠、无重叠、零长度或时钟不一致均不能作为兼容窗口。
- `compatible`：上述检查通过，模型统计起点在资源进程启动后且在模型首次读取前，两个窗口有完整覆盖。版本2还要求身份吻合；版本1只表示时间和数据兼容，仍缺少身份。
- `sameProcessVerified`：版本2前后快照三项身份一致且与资源PID/精确创建时间/程序摘要吻合、资源身份与程序保持时为true；版本1始终false。资源短窗口或阈值不通过时，身份仍可能匹配，但`compatible=false`。
- `businessAcceptancePassed=false`：始终保留；身份吻合或接口传输完成不能证明真实QQ回复成功，不关闭真实负载待办。

双来源模式的退出码0表示资料兼容；版本1关联仍未证明，版本2身份核对另见`sameProcessVerified`及三项`processComparison`。退出2表示资料有效却不兼容（资源短窗口、停止、身份不合、资源/日志检查不通过或时间范围不合）；退出1表示文件/计数/样本/摘要无效或输出失败。结果中的固定问题代码指出原因。判断结果要同时看模式、对应通过字段、身份及始终为false的业务验收字段，不能只凭退出码0认定业务通过。模型窗口可以较短，兼容不代表持续负载充分；按浏览器毫秒口径为0秒的窗口不能关联，完全位于资源窗口之外时优先标记无重合。

输入限制为每份JSON不超过1MiB、样本文件不超过64MiB、最多100000条、每行不超过4096字节。时间支持UTC和明确的时区偏移，最多9位小数；采样墙钟与累计秒数偏差超过1秒会标记不可用于时间关联。原始日志正文不读取。人工更改文件仍可能生成自洽数据，摘要只用于辨认这次读取的文件，不是来源签名。
