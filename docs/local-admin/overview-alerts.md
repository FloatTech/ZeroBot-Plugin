# 运行概览与近期异常

登录本机后台后进入“运行概览”，查看当前 OneBot 连接、账号、运行时间及近期异常。账号来自当前连接注册表，只表示 OneBot 已接入；QQ 登录由 NapCat 管理。

概览显示本次启动仍保留日志中的警告和错误数量，并列出最新 5 条 warning/error/fatal/panic 记录，先显示最近一条。日志继续脱敏，按文字显示；不包括重启前或已被淘汰的记录。出现记录不代表故障仍未解决，应结合时间、当前连接和“运行日志”判断。

概览可手动刷新，停留在可见概览页时每 10 秒更新；切页、隐藏或退出后取消读取，回来重新获取。读取失败会明确标记状态过期，账号区不继续显示为在线。异常日志读取失败不会把正常 OneBot 连接误报为断开。

功能只读，不发送 QQ 消息、不调用模型、不修改配置，无需设置新的密钥。详细排查可进入“运行日志”筛选并导出；本机素材校验服务器不可达的警告可能继续存在，应以程序是否正常初始化为准。

插件列表读取失败单独提示，不会改变概览的连接状态。概览刷新只更新概览；插件开关通过插件页的“重新加载状态”取得当前网页/聊天设置，不在概览轮询时重绘插件编辑表单。
