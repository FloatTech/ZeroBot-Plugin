# 日志查看与验证

## 使用与范围

刷新并重新登录 [本机后台](http://127.0.0.1:3010/)，选择左侧“运行日志”。可按级别和关键词筛选，关键词搜索的是脱敏后的文字。点击“暂停更新”停止读取，点击“恢复更新”继续；取消“自动滚动”后仍更新记录，方便停留阅读。“重新加载日志”读取近期记录，保留当前已应用的筛选。

每两秒进行一次有认证的短请求，仅当前日志页可见且未暂停时读取。切换页面、窗口隐藏、退出登录或关闭页面会停止轮询并取消当前请求；没有日志订阅或长连接。读取失败有提示并自动重试，退出后清空页面记录，不显示迟到的请求结果。

保留本次启动后接入的标准 logrus 日志，最多 1000 条且消息总量不超过 1 MiB；每条文字约 2 KiB，超出显示截断提示。浏览器最多保留 1000 条记录；首次读取近期最多 200 条，之后按游标获取新记录。暂停期间旧记录过期会提示断档；进程重启后识别新实例并重新读取。不会提高原日志级别，因此未启用 debug/trace 时没有对应记录。

日志只读，不更改启动配置、AI 参数或插件开关；不读取或公开历史 stderr 文件，不提供文件路径参数和导出接口。启用后台时安装日志钩子和脱敏格式包装，原输出目标及格式风格保留；未启用后台时不安装。

## 凭据与并发

入缓冲前隐藏认证头、Cookie、常见密钥/密码字段、URL 用户密码及全部查询/片段信息，隐藏收发消息正文和设置 AI 密钥的命令文本。启动时保护已有 OneBot 和 AI 凭据；读取时再次从当前保存与运行配置补充凭据，对保留记录重新脱敏。新网页提交的密钥和 Token 在尝试保存前加入保护集；已知密钥也匹配常见 URL/JSON 转义形式。标准 logrus 后续输出使用相同保护规则，既有历史文件不重写。

凭据历史集合有上限；超过上限后隐藏全部日志文字直到重启，避免不断累积密钥版本导致内存增长。当前配置读取失败时日志接口返回安全的 503，拒绝输出未经当前凭据保护的记录。网页用 textContent 创建文字，不把日志当 HTML 执行。

日志钩子与格式包装不访问数据库或文件，避免控制写入在持有 Manager 锁时日志回调再次争抢同一锁。配置刷新在日志缓冲锁之外完成；读写使用短临界区，缓冲有条数和字节上限。没有按客户端保存订阅状态。

本阶段保护已配置凭据及常见认证结构，不声称识别所有自定义插件未知格式的秘密。其他独立 logger、fmt 输出与程序初始化阶段的旧日志不属于此钩子范围，网页不读取这些输出。

`node --test scripts/test-log-ui.mjs` 三组离线 DOM 行为测试通过：日志中的脚本样本只作为文字、去重与页面上限、自动滚动开关；切页、暂停、隐藏和退出取消读取；迟到结果拒绝、筛选重置及失败重试。该测试不操作真实浏览器，不代替视觉与人工验收。
