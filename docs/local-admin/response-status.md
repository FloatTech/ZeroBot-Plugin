# 插件页响应状态说明

登录本机后台进入“插件列表”，选择全局或填写群号并“查看此范围”。“响应状态说明”显示最近一次成功读取范围的全局响应、该群单独响应及响应来源。点击“刷新插件状态”重新读取；输入但未读取的群号、插件开关草稿和搜索筛选不改变说明目标，切后台页面保留。刷新/切范围失败保留上次成功结果，并按错误提示重新核对；退出或会话过期清空，旧请求不回填。

现有规则是全局响应或该群单独响应任一开启即可通过响应检查。全局响应开启时，群单独响应关闭也不能阻止该群响应；全局沉默后，已单独开启的群仍可响应。全局视图只表示全局入口，不能据此判断所有群沉默，应读取具体群查看。卡片中的启用/禁用仍表示插件开关规则；回复还取决于响应状态、封禁、权限、@ 和具体指令，不以开启状态保证一定回复。

本页只读，不自动发送 QQ 指令或更改响应。需要调整时沿用原指令：主人私聊发送 /全局响应 或 /全局沉默；群内由主人或群管理员 @机器人后发送 /响应 或 /沉默。群内管理仍要求 @，原权限、缓存与写前备份不变。全局开启覆盖单独沉默，全局关闭不清除各群已设置的响应。

状态从当前实例统一控制层的持久化规则读取，不展示扩展内容、模型密钥或 Token，不把读取失败当作关闭。实例未接入控制层或插件分属多个控制管理器时提示不能读取统一状态，不推断响应。该入口只查看全局或正数群号，不提供私聊会话、封禁/解封或网页响应编辑。

验收可刷新全局说明，再读取自己机器人的一个群，核对目标和三项状态；修改开关草稿或未读取群号不影响原说明，再放弃草稿即可。无需修改日常响应，状态组合、失败及消息回归采用隔离配置测试。真实 QQ 完整业务保持原待办。
